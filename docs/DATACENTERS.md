# 미국 데이터센터 전력 지도 — 사용 가이드

`/#/world` (세계 현황판) 안의 **모드**. 상단 중앙 토글에서 `세계·무역 ↔ 미국 데이터센터` 전환.
별도 탭이 아니라 세계 지도 위에 올라가는 모드다. 구현: [`client/src/pages/World.tsx`](../client/src/pages/World.tsx).
입력 데이터: [`docs/README_ai_datacenters.md`](README_ai_datacenters.md) (25개 사이트, 2026-08 기준).

이 지도가 답하는 질문: **"각 데이터센터가 전력을 어디서 끌어오는가, 그 부하가 그 지역 전력망에 얼마나 무겁게 앉았는가."**

---

## 0. 핵심 원칙 — 스케일별 서사 분리

**사실인 연결일수록 거리가 0에 수렴한다**(현장 발전=거리 0, 유틸 신설=인접). 그래서 스케일마다 다른 이야기를 한다:

| 스케일 | 답하는 질문 | 무엇이 보이나 |
|---|---|---|
| **국가 뷰**(기본) | 누가 어느 전력시장에, 얼마나 무겁게 앉았나 (귀속·부담) | 면 채색이 주역. 연결선·흐름 애니메이션 **안 보임** |
| **사이트 줌**(확대) | 생산 → 송전 → DC 흐름 | ①②③ 연결선 + 흐름 애니메이션 + 계통 스냅 점선이 이때만 **살아남** |

- 전환 기준: DC 모드 진입 시 미국-핏 배율의 **1.4배 이상**으로 확대하면 사이트 줌. (대략 주 하나가 화면을 채울 때쯤)
- 즉 연결선이 안 보이면 **더 확대**하면 된다.

## 1. 컨트롤 — 좌상단 패널 + 우상단 알약(세계·무역 모드와 통일)

### 좌상단 ① 그룹 (마커 색) — 마커는 항상 그룹으로 색 구분

| 그룹 | 뜻 | 색 |
|---|---|---|
| **A** 스타게이트 계열 | 개발사 SPV + 투자등급 임차인 리스 | 보라 |
| **B** 하이퍼스케일러 | 자체 보유 | 파랑 |
| **C** 네오클라우드 | 개발사·GPU 담보 | 분홍 |

A/B/C 칩 = 범례 겸 **필터**(클릭 토글). 마커 색은 그룹 하나로 고정 — **전력계통(ISO)은 아래 면 채색·전력시장이 전담**(중복 제거), **신용등급은 사이트 카드**에.

### 좌상단 ② 면 채색 — 국가 뷰 배경 (3종 상호배타)

같은 채널(면)이라 하나만 켜진다.

| 토글 | 질문 | 데이터 |
|---|---|---|
| **없음** | — | 배경 없음 |
| **전력시장** | 누구 전기인가 (귀속) | ISO/RTO 권역 폴리곤 채색. ERCOT 빨강·PJM 파랑·MISO 초록·SPP 주황·CAISO 분홍·ISONE 보라·NYISO 청록. **비ISO(TVA·WECC·SERC 등)는 무채색.** 경계는 겹침·공백 있는 **근사**(HIFLD) |
| **AI 부하 비중** | 얼마나 무겁게 (부담) | 주별 램프 채색 → **아래 2절** |

각 항목은 **온커서 설명**(ⓘ·버튼 hover) 제공.

### 우상단 알약 (세계·무역의 항로/항만/해협과 동일 위치·스타일) — 레이어 on/off

- **⚛ 원전·SMR** — 회사 단위 원전·SMR 계약 13건. 특정 DC로 선을 잇지 않음(대부분 계통에 흘려넣는 회사 계약). **노란색 ⚛**. 실선+중심점 = 기존·퇴역 부지 재활용(Crane=구 TMI 재가동·Susquehanna·Clinton → 기존 접속점, 빠른 접속) / 점선 = 신규 건설(SMR·페르미 AP1000 → 느림·불확실).
- **⚡ 송전선** — 345kV+ 고압 송전선(HIFLD, **2022 기준**·신설선 미포함). **하늘색 + 흐르는 점선 애니메이션**(전력이 흐르는 느낌). 전압 등급별 굵기·투명도(345 얇고 옅게 → 500 → 765kV 굵고 진하게 = 전송 용량 프록시, 실시간 전력량 아님). 사이트 줌에서 계통 급전 DC → 최근접 선로로 **스냅 점선**(근사).

## 2. "AI 부하 비중"은 어떻게 계산되나

> **주내 AI 데이터센터 목표부하 합 ÷ 그 주의 평균 전력부하 × 100 (%)**

한 주의 전력망에 AI 데이터센터가 얼마나 큰 비중으로 얹혔는지. 절대량(총 소비)이 아니라 **비율**이라 인구 지도와 구분된다.

**분자** = 주내 각 DC의 목표 IT 부하(MW) 합
- `capacity_target_mw.max`(공표 목표 상한). 없으면 min, 그것도 없으면 운영 용량.
- **페르미 마타도어 제외** — 11~17GW는 "확보 전력 계획치"라 다른 사이트의 IT 부하와 단위가 달라 왜곡됨.

**분모** = 그 주의 평균 전력부하(MW)
- = 주 연간 총 소매 전력판매량(MWh) ÷ 8760시간
- 출처: **EIA 2023 State Electricity Profiles**(2024-10-23 공표). 코드의 `STATE_RETAIL_MWH_2023`.

**예 (루이지애나)**: Hyperion 목표 5,000MW ÷ (95,374,457 MWh ÷ 8760 = 10,887MW 평균부하) = **46%**.

**단계 램프**(누적 임계, 진할수록 무거움): `≥45%` → `30–45` → `15–30` → `5–15` → `<5`.
주에 마우스를 올리면 `루이지애나 · AI 부하 46%` 처럼 뜬다.

**현재 순위**(2026-09): WI 54% · **LA 46%** · MS 36% · NM 31% · ND 21% · IN 20% · TX 19% · MI 13% · OH 6% …
- 소규모 계통에 메가 DC가 앉은 주(WI·LA·MS)가 최상위 — 이게 이 지표의 핵심 인사이트.
- ⚠ WI가 LA를 근소하게 앞섬(위스콘신에 MSFT 페어워터 3.3GW + 스타게이트 라이트하우스 0.9GW 둘). 지표 정의(목표 vs 운영, 상한 처리)는 조정 여지 있음 — **fable 검토 대기 중**.

## 3. 마커(원) 읽는 법

한 원 = 데이터센터 하나.

| 인코딩 | 뜻 |
|---|---|
| **원 크기** | IT 용량(MW) |
| **외곽 링 채움** | 계통 의존도 — 꽉 참=100% 계통 / 빈 링=현장발전 위주 / 점선=미공개 |
| **내부 아이콘** | 현장 발전원 — 가스 🔥 · 원전 ⚛ · 배터리 |
| **점선 원판** | 페르미(확보 전력, 단위 다름 — 크기 스케일에서 제외) |

호버하면 문장으로 답한다: 예) `스타게이트 애빌린 · TX` / `1.2GW · 현장 가스 위주(계통 minimal)`.

**사각형** = 발전소(①·② 연결선이 있는 것만). 가스=주황, 원전=초록.

## 4. 연결선 3계급 (사이트 줌에서만) — "흐름 애니메이션은 물리 전용에만"

계통은 풀(pool)이라 문자 그대로의 전자 흐름은 물리 전용 연결에서만 사실이다. 그래서 흐름 연출도 ①에만 허용.

| 계급 | 뜻 | 시각 | 흐름 애니메이션 |
|---|---|---|---|
| **① 물리** | 현장 발전, 페르미 사설망(가스 6GW + AP1000) | 실선 | **있음** (유일하게 사실인 조류) |
| **② 계약** | 유틸이 이 부하 때문에 신설(예: Hyperion → Entergy 가스복합) | 긴 대시 | 없음 (호버: "계약 관계 · 물리 조류 아님") |
| **③ 계통** | 일반 계통 급전 | 최근접 345kV로 **근사 스냅 점선** — 발전소 특정 안 함 | 없음 |

## 5. 정직성 각주 (지도가 감추지 않는 한계)

- **송전선**: 기존 계통 2022년 기준, 이후 신설선 미포함.
- **③ 계통 스냅**: `근사` — 실제 인입선·변전소는 비공개(EIA).
- **RTO 경계**: 겹침·공백 있는 대략적 경계(HIFLD·EIA 주석).
- **페르미**: 확보 계획치라 IT 부하와 단위 다름.
- **완공률(%)은 데이터 없음** — 어느 회사도 공시 안 함. 목표 대비 게이지 만들지 말 것.
