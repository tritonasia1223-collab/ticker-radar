# 국제 연표 조사 도표 보충 · 2026-11-19

사용자 요청: 인사이트 조사 도표와 국제 연표의 대조 결과를 보충하고, 수치 변화는 `이전 값 → 이후 값`으로 표시한다. 오른쪽 값만 상승은 빨강(`c-r`), 하락은 파랑(`c-b`)으로 표시한다. 환율은 통화 가치 평가가 아니라 표시된 숫자의 증감을 따른다. 날짜·서로 다른 지표·단순 인과 화살표에는 이 규칙을 기계적으로 적용하지 않는다.

## 적용 범위

- 새 사건 27건. 기존 238건에 더해 기본 데이터는 265건(국가/공동 249건, 국제 대사건 16건).
- 기존 카드 32건의 설명·정합성·수치 표기를 보충. 새 카드마다 `event`, `policy`, `stat` 분류를 지정.
- 기존 폰트·색상 체계·배치·글래스·모션은 변경하지 않는다. 숫자 강조는 기존 편집기의 색 마커를 사용한다.
- 인사이트 원문 카드는 수정하지 않는다. 반복 연간 통계와 정권 교체를 모두 새 카드로 옮기기보다 금융·통화·통상 흐름을 이해하는 데 필요한 항목을 우선한다.

새 사건: 미일 섬유 협상, MCA, 프랑스 39시간제, 베이커 플랜, 뉴욕은행 결제 사고, 1986년 유가 급락과 파운드 압력, FSLIC 위기, 영구 FRN 거래 경색, 미영 자본규제 공동안, 바젤 초안, 씨티 충당금, 반도체 보복관세, 하노버·들로르 위원회, 브뤼헤 연설, 첫 환율보고서, 수퍼301, SII 개시·타결, FIRREA, 쿠웨이트 침공, 걸프전 공습, 일본의 재정 기여, BCCI, 살로몬 입찰 위반, 덴마크 국민투표, 바젤 감독 최소기준.

## 검증 과정에서 구분한 사실

- MCA의 제도화는 1969년의 환율 조정 자체와 구분해 1971년 5월에 배치.
- 프랑스의 당시 시행된 법정 근로시간은 1982년 39시간. 기존 1981년 카드의 35시간 시행처럼 읽히던 구절은 단축 추진으로 정리.
- 1986년 유가 급락이 영국의 즉각적인 금리 인하를 뜻하지는 않음. 연초 환율 방어 금리 인상도 있었음을 반영.
- 독일의 1992년 7월 재할인율은 8%에서 8.75%로 인상, 롬바르트 금리는 9.75% 유지. 두 금리를 혼동하지 않음.
- 동서독 통화교환은 임금·연금의 1:1, 일정 한도 외 예금의 원칙적 2:1을 구분.
- BCCI 후속 감독 기준과 바젤Ⅰ의 8% 자본비율은 별도 사건.
- 독일이 영국을 전혀 지원하지 않았다는 단정, 1992년 재팬 프리미엄 등 확인이 부족하거나 과도하게 단순화된 표현은 추가하지 않음.

## 원문 보존과 저장

`client/src/data/international-timeline-supplement.json`에 신규 사건, 수정 전후 전문과 사건별 근거 URL을 보존했다. 기존 조사 카드의 로컬 스냅샷은 `docs/audits/international-timeline-20261119/source-card.json`이다.

`mergeSupplementTimeline`은 새 revision당 한 번 실행된다. 수정 전 제목·본문이 모두 일치할 때만 보충 문안을 적용한다. 이미 편집된 제목·본문, 날짜·유형·국가 라벨, 사용자 추가 카드, 휴지통은 보존한다. 비어 있거나 완전히 사용자 카드로 교체한 모음에는 주입하지 않는다. 신규 보충 사건을 삭제해도 재접속 때 되살리지 않는다.

적용 전 브라우저 원본을 `fiscus-international-timeline-before-audit-supplement-20261119`로 백업한다. 백업 실패 시 기존 오류 경로로 저장을 잠근다. 저장 위치는 여전히 브라우저·주소별 localStorage이며, 로컬과 운영 간 편집 동기화를 새로 구현한 것은 아니다.

- 78개 테스트 파일, 620개 테스트 통과.
