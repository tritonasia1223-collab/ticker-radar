# 미국 유동성 탭 — 국채 수급 데이터 인벤토리 (fable 전달용)

> 목적: "연준의 국채 매입·보유(만기별)" 섹션을 어떻게 재구성할지 논의. 아래는 **현재 실제로 쓰는 데이터와 계산식** 전부.
> 전제: 전부 **키 없는 공개 API**, 값은 **백만 달러(million USD)**로 정규화해 저장(테이블 `fed_balance_sheet(seriesId, obsDate, valueMusd)`).

## A. 연준 보유 — 만기별 (주간, FRED)

| 코드(FRED) | 의미 |
|---|---|
| `WSHOBL` | 단기 **Bills** |
| `WSHONBNL` | 중장기 **Notes·Bonds (nominal)** — ⚠ **FRN 포함**, Notes/Bonds 분리 불가 |
| `WSHONBIIL` | **TIPS** (물가연동, inflation-indexed) |
| `WSHOTSL` | **총 국채보유** (= `TREAST`, 교차검증 앵커) |
| `WSHOICL` | 물가보정분(inflation compensation) — 파생에서 흡수 |

**⚠ 결정적 한계**: 연준 H.4.1은 만기를 **딱 3버킷**(Bills / 중장기 Notes+Bonds 합산 / TIPS)만 공개.
- Notes vs Bonds vs FRN **분리 불가** (원천에 없음).
- **그로스 매입액 없음** — 레벨(보유잔액)만 나옴. 따라서 "매입량"은 **보유량 변화(ΔHoldings)**로만 잡힘 = **순매입 − 만기상환 − 매도**. QT 롤오프로 줄면 **음수**.

---

## B. 재무부 발행잔액 — 종류별 (월간, MSPD)

| 합성 코드 | 의미(MSPD security_class) |
|---|---|
| `MKT_BILLS` | Bills |
| `MKT_NOTES` | Notes |
| `MKT_BONDS` | Bonds |
| `MKT_TIPS` | TIPS |
| `MKT_FRN` | Floating Rate Notes |

- 시장성(Marketable) 5종 **전부** 분리됨. `MarketTotal = 5종 합`.
- **월간 MoM Δ = 순발행**(발행 − 상환).
- 종류별 데이터 시작 **≈2014년** (그 이전은 종류 분해 없음). 잔액 백필은 2010~.

## 현재 결합/파생 계산

**만기 매칭** (연준 3버킷 ↔ 시장):
- 단기 = 연준 `WSHOBL` ↔ 시장 `MKT_BILLS`
- 중장기 = 연준 `WSHONBNL` ↔ 시장 `MKT_NOTES + MKT_BONDS + MKT_FRN` (연준 nominal이 FRN 포함하므로 분모도 합산)
- TIPS = 연준 `(WSHOTSL − WSHOBL − WSHONBNL)` ↔ 시장 `MKT_TIPS`

**주간↔월간 시차**: 시장(월간)을 각 주에 **forward-fill**(그 주 날짜 이하 최근 월말 값). → 월중엔 분모 고정, 분자(연준)만 움직임.

**현재 화면에 그려진 값**:
1. 재무부 발행 섹션: 종류별 잔액(5종 스택) + **월별 순발행**(5종, MoM Δ). ← 공급 플로우 **이미 있음**.
2. 연준 섹션(현재): **3버킷 보유량 누적 area(스톡)** + "흡수율" 수치.
   - 흡수율 = 보유량 ÷ 시장발행잔액 (전체 및 버킷별). ← **파생 비율**.

**지금 문제(논의 핵심)**: 연준 섹션이 "흡수율(비율)"을 헤드라인으로 올려서, 정작 원했던 **① 만기별 매입량(플로우 ΔHoldings)이 빠졌고** ② 보유량도 "흡수" 렌즈로 가려짐. 본말전도.

## 아직 없는 데이터 ("누가 사갔는지" — 원 기획엔 있었으나 미수집)

- **경매 낙찰자 구성**(auction: primary dealer / direct / indirect bid) — 미수집
- **외국인 보유**(TIC, 국가별) — 미수집
- **부문별 보유**(Z.1 Flow of Funds, sector) — 미수집

→ 이걸 붙이면 "공급(순발행) → 연준 흡수 + 민간 + 해외" 완전한 수급 그림이 됨. 현재는 **공급(재무부) + 연준(수요 일부)**만.

## 논의 중인 재구성 방향(초안, 확정 아님)

- 섹션명: "연준의 국채 흡수" → **"연준의 국채 매입·보유(만기별)"**
- **매입량(플로우, ΔHoldings)** 추가 — `+`=매입 / `−`=축소(QT). 주간 Δ(노이즈 큼) vs 월간 Δ(순발행과 같은 축) 중 택.
- **보유량(스톡)** 유지 — 만기별 누적.
- **흡수율/보유비중**은 강등(작은 참고 수치) 또는 제거.
- 라벨 정직성: 데이터상 "순매입"이 아니라 엄밀히는 "보유 증감(ΔHoldings)".

## fable에게 물어보면 좋을 것
1. 매입량 주기: 주간 Δ(해상도) vs 월간 Δ(순발행과 비교 가능·평활) — 어느 쪽?
2. 매입량 & 보유량: 토글로 하나씩 vs 상시 2단?
3. 흡수율(비율)을 완전히 뺄지, 참고 수치로 남길지?
4. "누가 사갔는지"(auction/TIC/Z.1)까지 스코프 확장할지, 아니면 연준 매입·보유부터 마무리?
5. ΔHoldings를 "순매입"으로 부르는 게 정직한지(만기상환·매도 섞임) — 라벨 제안?
