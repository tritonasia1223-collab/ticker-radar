## 변경 범위

`shared/cap-text-merge.ts`의 동일 비교 규칙을 서버 트랜잭션과 클라이언트 재비교에서 사용한다. 같은 문장/셀의 독립 수정을 합치며 낱말·숫자가 겹치면 문장 단위로 선택한다. 색·강조·링크 표식을 유지하고 안전한 블록/표의 대응을 비교한다. 표 열 추가와 기존 셀 수정도 함께 남긴다. 위치 대응이 모호한 재배치·삭제는 자동으로 추측하지 않는다.

`CapConflictWizard`는 원문/내 수정/다른 편집자 수정을 노란 하이라이트와 함께 한 곳씩 보여준다. 선택 후 자동 이동, 이전 선택 보존, 직접 문장 입력과 명시적 확정을 지원한다. 실제 저장은 기존 협업 저장기·IndexedDB·비교 저장·재시도를 사용한다. 삭제된 항목의 복원에는 추가 체크가 필요하다.

블록의 검색용 text/tables/images 미러를 함께 관리해 같은 문장을 두 번 선택하지 않는다. 운영 요청 경로나 DB 스키마를 추가하지 않았다. 사용자 피드백 원문과 적용 범위는 `docs/COLLABORATION.md`에 기록했다.
