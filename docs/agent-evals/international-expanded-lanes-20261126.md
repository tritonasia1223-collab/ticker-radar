# 소련·신흥국 레인 추가 검증

요청: 기존 국제 연표에 참고 인사이트의 소련·신흥국 내용을 1992년까지 추가한다.

- 최신 운영 코드 `b49b510` 기반. DB 전체 설정 교체·스키마 변경 없이 사건별 추가만 수행한다.
- 자료 62개: 소련·러시아 36 / 신흥국 26, 이 중 월 미상 연간 27개. 소련의 에너지·곡물 교역, 서방 제재, 개혁과 해체를 배치한다. 신흥국은 중남미 차입·외채위기와 한국·대만의 흑자·환율·자산시장·개방을 중심으로 정리한다.
- 1992년을 넘는 사건과 원문에 없는 월을 추정해 추가하지 않는다. 기존 대사건 띠와 유럽 공동 블록을 유지한다.
- TypeScript, 93개 테스트 파일 / 719개 테스트, 프로덕션 빌드 통과. 기존 Browserslist·대형 World 청크 경고 유지.
- 실제 Postgres 임시 스키마에서 소련 메타데이터 저장·재조회·본문 수정과 기존 병합·충돌·삭제 경합·멱등성·동기화 검증 통과. 테스트 스키마 정리 완료.
- 자동 검증: 원본 5개국 순서와 유럽 공동 span 유지, 7개 기본 레인, 연월 정렬, 기간 종료, 라벨 제거 후 레인 유지, 구버전 스키마와 메타데이터 왕복, type 필터 적용 시 대사건 유지.
- 로컬 UI는 운영 쓰기와 분리한 임시 메모리 API에서 검증한다. 운영 내용은 저장 전 별도 스냅샷 및 가져오기 기록으로 보존한다.
