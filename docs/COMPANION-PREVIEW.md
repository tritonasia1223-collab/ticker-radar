# 피스 — 대화 비서 로컬 시안

2026-11-27 요청: 웹앱 위의 떠다니는 봇과 대화창부터 확인한다. 앱 자료 조회와 수정 권한은 연결하지 않는다.

실행: 저장소 루트에서 `npx.cmd tsx script/preview-companion.ts` 후 <http://127.0.0.1:5197/#/international-timeline>을 연다.

- 캐릭터 클릭: 열기/최소화. 드래그: 위치 이동.
- Enter 전송, Shift+Enter 줄바꿈, Escape 최소화. 한국어 조합 중 Enter는 전송하지 않는다.
- `+`: 새 대화. 메시지와 입력 초안은 컴포넌트 메모리에만 보관하며 페이지 이동/최소화 시 유지, 새로고침 시 삭제된다.
- 미리보기와 예시 답변을 명시한다. GPT 실제 답변은 아니다.
- 봇은 네트워크 요청, 자료 검색, 파일 접근, DB 조회·수정 기능이 없다. 입력한 대화는 외부로 전송하거나 별도로 저장하지 않는다.

시안 서버는 loopback에만 바인딩하며 프로덕션 서버/DB 모듈을 가져오지 않는다. 모든 `/api` 요청을 차단한다. 국제 연표의 저장소 내 정적 자료로 배경 화면을 확인한다. 다른 페이지의 서버 조회는 제한된다.

2026-11-27 사용자가 완성 후 운영 배포를 요청했다. 위젯은 앱 공통 영역에서 지연 로드되며 운영에서도 사용할 수 있다. 예시 대화 상태를 계속 표시한다.

첨부된 보라색 보물상자를 바탕으로 Three.js 입체 모델을 구성했다. 이미지 평면을 붙이는 방식이 아닌 메시 기반 모델이며 원본을 해석해 재현한 형태다. 대기 시 손 흔들기와 눈 깜박임, 드래그 중 걷기, 답변 대기 중 물음표, 응답 완료 시 뚜껑 열기와 동전·별을 표현한다. WebGL을 사용할 수 없으면 간단한 대체 캐릭터를 표시한다. 화면 밖과 숨겨진 탭에서는 렌더링을 쉬고, 동작 줄이기 설정을 존중한다.

다크 모드 토글과 테마 전환 기능을 제거하고 ThemeProvider를 라이트 전용으로 고정했다. 이전 운영 소스에도 토글이 남아 있었음을 확인했다. 차트에서 사용하는 theme 값은 호환성을 유지하며 항상 light를 반환한다.

GPT 연결은 후속 작업이다. 현재 API 키가 설정되어 있지 않고 자동 승인 검토가 외부 대화 전송과 운영 자료 프록시 연결을 거부하여 해당 연결 코드는 제거했다. 사용자가 외부 전송 범위를 승인하면 서버 키 기반의 대화 전용 API를 연결한다. 사용자 입력 대화만 전송하고 앱 자료는 전송하지 않는 범위를 우선 제안한다.
