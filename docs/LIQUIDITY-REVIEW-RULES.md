# B안 상단 리뷰 작성 규칙

사용자 검토를 반영한 문장형 포맷. 상단은 리뷰, 하단은 지표별 그래프와 근거다. 상단에 요인별 막대·카드 대시보드를 다시 추가하지 않는다.

## 문체와 순서

1. 메인: “유동성은 N주간 X억 달러 늘었습니다/줄었습니다.” 주차·비교 기간에 맞춰 계산한다.
2. 어디서: 절대 기여액이 가장 큰 요인을 먼저 쓰고, 항목 이름을 반복하지 않고 각 설명 앞에 단순 글머리표를 붙인다. 양방향이면 상쇄를 명시한다.
3. 어디로: 지급준비금과 현금통화·기타의 변화. 어디서/어디로 사이는 점선으로 구분하고 화살표는 두지 않는다.
4. 국채: “국채는 N주간 순액으로 X억 달러 늘었습니다/줄었습니다” 아래 ‘얼마나 발행했나?’와 ‘이걸 누가 받아갔나?’ 두 항목만 둔다. 첫 항목에 발행·롤오버, 순증감·단기채, 산출 방법을 합친다. 두 항목 사이는 점선 하나로 구분한다.
5. 신용: 정상일 때 한 문장. 이상 시 해당 경로만 옅은 경고색으로 관측 → 크기 → 의미를 서술한다. 네 경로를 항상 나열하지 않는다.

결론을 먼저 쓴다. 숫자는 설명하는 문장에 붙인다. 용어 정의는 짧은 보조 문장, 계산 세부는 펼치기로 둔다. “함께 읽습니다”, “차례로 확인합니다” 같은 진행 안내를 넣지 않는다. 관측 사실은 확정형, 원인·위험 해석은 가능성으로 쓴다.

## 개요 표시

- 개요는 문장이 끝날 때마다 줄바꿈한다. 소수점(7.9조, 75.1%)에서는 나누지 않는다.
- 왼쪽 제목은 ‘개요’, 작은 설명은 ‘각 항목의 근거와 데이터는 아래에서 확인’. 다른 소제목과 같은 높이로 스크롤을 따라오고 개요 영역 끝에서 멈춘다.
- 증가 금액은 초록, 감소 금액은 빨강. ‘어디서’는 잔고 자체가 아니라 순유동성 기여 방향을 사용한다(역레포 회수·TGA 사용은 초록).
- 지급준비금·현금통화·국채 순증감은 각 항목의 증감 방향으로 표시한다. 총발행액·낙찰액처럼 변화량이 아닌 금액은 중립색을 유지한다.
- 작은 보조 설명은 옅은 회색으로 구분한다. 신용 요약과 자금시장 경고 왼쪽에는 ‘위험 신호는?’을 표시한다.

## 유동성 방향

- Δ순유동성 = Δ연준 자산 − ΔTGA − Δ역레포. 억 단위 반올림은 표시에서만 수행한다.
- 역레포 감소: MMF 등이 맡긴 돈을 **순회수**. 증가: 추가 예치.
- TGA 감소: 순액으로 자금 사용·시중 방출. 증가: 자금 축적·유동성 흡수. 총지출액과 혼동하지 않는다.
- 연준 자산 증감은 유동성 기여로 표현한다. 자산 증가 전부를 국채 매입으로 쓰지 않는다.
- 지급준비금·현금통화·기타는 같은 기간의 회계상 잔액 변화다. 특정 MMF 자금이 특정 은행으로 이동했다고 단정하지 않는다.
- “대부분/나머지”는 지준 변화가 순유동성과 같은 방향이고 순변화의 50~100%일 때만 사용한다. 반대 방향·상쇄·0·비교 자료 없음은 따로 설명한다.

## 국채 집계

- 입찰 합계는 결제 구간의 정확한 시작·종료일을 표시한다. 9월 23일까지를 “7~9월 전체”로 쓰지 않는다.
- 발행 설명의 롤오버 규모는 같은 기간 상환액/발행액의 근사치다. 90~100%이면 ‘거의 대부분’, 50~90%이면 ‘절반 이상’, 그 미만이면 ‘물량도 포함’으로 쓴다. 상환액이 더 크면 그 사실을 별도로 쓴다.
- 산출 방법은 ‘순증감 = 발행 − 상환 + 물가 조정’과 실제 억 달러 단위 계산식을 맨 위에 둔다. 비고는 기간·출처·액면가 기준·롤오버 근사치로 압축하고 휴일 조정은 해당할 때만 표시한다.
- B안 국채 개요는 DTS III-A 시장성 국채(Federal Financing Bank 제외)의 실제 발행·상환 연누계 차감으로 계산한다. 비교일 제외/선택일 포함, 상단 4주·13주와 동일하다. 회계연도 전환 시 전년도 말 누계를 더한다. 순증감 = 발행 − 상환 + 물가연동국채 원금 조정. 현금 조달액과 구분한다.
- 영업일 기준 관측이 없으면 미공표로 표시하며 월말 잔액·직전 주 값으로 대체하지 않는다. 공식 공휴일과 주말에만 직전 영업일을 사용한다. 일일 자료는 6시간 캐시로 재조회한다.
- 입찰·생키도 같은 결제일 구간으로 통일한다. 단기채 제외 버튼은 생키의 범위만 바꾸며 개요의 전체 발행·상환 금액에는 영향을 주지 않는다. 기존 A안의 달력 월 조회는 유지한다.
- 입찰 낙찰액과 DTS 발행액은 같은 기간이어도 조정·포괄 범위가 다르다. 낙찰 주체를 DTS 총액의 분할처럼 쓰지 않는다. 기존 월말 잔액 자료는 상세 보유 자료에만 사용한다.
- 단기채 순증가 비중은 분자·분모의 시작/종료 관측이 동일하고 전체 순증가 > 0, 0 ≤ 단기채 순증가 ≤ 전체 순증가일 때만 표시한다. 그 외에는 별도 증감액으로 쓴다.
- 총발행과 순증감 기간이 다르면 “직접 대조할 수 없음”으로 한정한다. “정밀 파악 불가”로 자료 전체의 신뢰도를 부정하지 않는다.
- 딜러 금액은 `primary_dealer_accepted`의 직접 합계다. 다른 항목을 뺀 잔여 금액으로 계산하지 않는다. 비경쟁·기타 및 보고 총액/분류 합계 차이는 산출 근거에 표시하며 임의 배분하지 않는다.
- 딜러의 입찰 참여 요건 ≠ 낙찰액 전체의 의무 인수. 재판매되므로 낙찰액 ≠ 최종 보유액.
- SOMA 입찰 금액은 만기 국채 재투자(롤오버). 순매입·QE 금액으로 쓰지 않는다.
- 낙찰 주체 본문은 총액 → 간접 입찰자 → 프라이머리 딜러 → 직접 입찰자·연준 만기 재투자 순서로 줄바꿈한다. 간접 입찰자 정의·딜러 참여 요건·재판매 가능성은 본문 아래 옅은 보조 설명으로 한데 모은다.

공식 근거: [재무부 입찰 분류](https://www.treasurydirect.gov/help-center/faqs/auction-faqs/), [뉴욕 연은 딜러 요건](https://www.newyorkfed.org/markets/primarydealers), [SOMA 롤오버](https://www.newyorkfed.org/markets/treasury-rollover-faq).

## 신용 문장 분기

신용·시나리오 판정 임계값은 `shared/credit/credit_indicators.json`을 사용한다. 회사채 시장금리의 설명용 기준은 `shared/credit/reading-rules.json`에 분리하며 시나리오 점수에 넣지 않는다. `true`인 조건과 유효한 근거만 사용하며 결측·수집 실패·오래된 관측은 정상으로 바꾸지 않는다.

| 조건 | 결론과 해석 |
| --- | --- |
| CP 부담 + 은행 대출 급증 | 비상 인출 가능성을 최우선으로 표시. 좋은 대출 확장으로 서술하지 않음 |
| 은행 대출기준 강화 + 증가세 둔화 + 회사채 비용 상승 + 발행 감소 | 은행·회사채에서 동시 부담. 신용 공급 위축은 가능성으로 표현 |
| HY 확대 + IG 안정 | 신용등급이 낮은 기업에 집중된 부담 |
| 회사채 비용 상승 + 발행 자료 부족 | 가격 상승은 관측 사실. 실제 조달 감소는 판단 유보 |
| 대출수요 약화 단독 | 차입 수요 둔화. 은행의 공급 차단으로 쓰지 않음 |
| CP 잔액/비용, CCC, BDC, ETF 주의 조건 | 해당 경로와 실제 관측치를 서술. 사모대출 전체 손실로 일반화하지 않음 |
| 은행 주의 조건 모두 미충족 + IG/HY 안정 | “은행 대출에서 뚜렷한 위축 신호는 없고, IG·HY 회사채의 추가 금리도 안정적입니다.” 발행 미확인은 작은 보조 문장 |
| 자료 부족·혼합 | 확인된 영역만 서술. “모든 시장에 이상 없음” 금지 |

수치는 해당 신호의 근거에서 가져오고 기준일·비교 기간을 함께 표시한다. 4주 변화/13주 연율/직전 분기 변화/%/%p/배를 구분한다. 신호 판단은 A안과 같은 고정 기간이며 상단 비교 토글이 임계값을 바꾸지 않는다. 원인 설명은 “~했을 수 있습니다”, “~가능성이 있습니다”로 쓴다.

구현: `shared/liquidity-review.ts`, `shared/credit/review.ts`, `client/src/components/LiquidityDashboard.tsx`, `CreditReading.tsx`.
검증: `tests/liquidity-review.test.ts` 및 기존 유동성·신용 해설 테스트, 타입 검사, 빌드, 실제 화면의 주차/비교 기간/펼치기 확인.

## 시장금리와 위험 프리미엄

OAS 확대는 위험 프리미엄 확대라고 쓴다. OAS만으로 전체 조달금리가 올랐거나 내렸다고 단정하지 않는다. IG·HY 시장금리와 상단 비교 기간의 변화·관측일을 함께 표시한다.

회사채 섹션 본문은 쉬운 결론 → 금리 부담 → ‘스프레드는 국채 금리보다 추가로 요구하는 금리(프리미엄)를 뜻합니다.’ 순서다. 스프레드 정의는 본문과 같은 크기로 쓴다. 자료 범위·기존 평균 지급이자와의 차이·등급별 발행 미확인은 펼치는 보조 설명으로 내린다. IG·HY 안정 신호와 유효한 전체 발행을 확인했을 때만 ‘큰 문제는 포착되지 않았습니다’라고 쓰며, 긴장 신호를 우선한다. 높은 금리는 각각 확보 기간 백분위 80 이상, 최소 730일·400개 관측으로 정의한다. 과거의 낮은 금리·표본 부족에 현재 설명을 고정하지 않는다.

일일 국채 집계 구현: `shared/treasury-flow.ts`, `server/treasury-flow.ts`. 검증: `tests/treasury-flow.test.ts`, `tests/bond-reading.test.ts`.

## 순유동성·M2 상세 구간

- 01 제목은 “순유동성과 M2”로 쓴다. 잔액·증감 문장은 반복하지 않고 각 파이 위에 잔액을 표시한다. 순유동성 산식은 총자산 − TGA − 역레포이며 “근사치”를 표시한다.
- “이 정도면 큰 변화인가”의 추이·백분위 블록 및 순유동성 중복 카드는 표시하지 않는다. 순유동성은 왼쪽, M2는 오른쪽 파이로 배치하고 범례는 각 원 아래에 모은다. 작은 화면에서는 세로로 배치한다.
- 파이 면적은 금액에 비례한다. 왼쪽 원 전체는 총자산(순유동성 + TGA + 역레포), 검은 조각이 순유동성이다. 지름은 공통 최대금액 대비 제곱근 비율로 계산한다.
- 각 제목 옆 `?`에 마우스를 올리거나 키보드로 초점을 맞추면 순유동성 차감식과 M2 다섯 항목의 합산식이 나온다. 터치로도 열 수 있다. 계산식은 본문에 반복하지 않으며, M2 기준월은 아래 범례 주석에 남긴다.
- 파이 조각에 마우스를 올리면 해당 조각만 3.5% 확대하고 은은한 글로우와 항목명·금액·비중 팝업을 표시한다. 원래 크기와 면적 비율은 유지하며 키보드 초점·터치로도 확인할 수 있다. 움직임 감소 설정에서는 전환 애니메이션을 끈다.
- 순유동성·M2 전년비 비교는 기본 접힘, 설명도 함께 펼친다. 용어는 “순유동성”으로 통일한다.
- M2 구성은 FRED의 CURRSL·DEMDEPSL·MDLM·STDSL·RMFSL, 은퇴계좌는 IRA·IRADI를 조회한다. 금액은 백만 달러로 통일하고 매월 갱신되는 자료를 기존 6시간 캐시로 조회한다.
- H.6 정의에 맞춰 소액 정기예금에서 IRADI, 개인 MMF에서 IRA−IRADI를 차감한다. 구성 항목은 계절조정, 은퇴계좌 차감은 비계절조정값이다. 일부 최신 은퇴계좌 관측은 연준 추정치다.
- 상단 선택 주차 이하의 최신 M2와 정확히 같은 관측월만 사용한다. 합계와 M2 차이가 공시 반올림 허용치(5억 달러)를 넘거나 항목이 없으면 구성비를 생략하고 사유를 표시한다. 이전 달이나 미래 관측으로 메우지 않는다. MDLM이 없는 2020년 5월 이전은 현 구성비를 표시하지 않는다.

공식 근거: [연준 H.6 표 2·3](https://www.federalreserve.gov/releases/h6/Current/).

## 02 어디서 기여도 막대

- 제목은 순유동성 증가 시 “풀린 N억 달러를 분해해보면”, 감소 시 “흡수된 N억 달러를 분해해보면”으로 표시한다. 금액은 절댓값이며 증가 금액은 초록, 감소 금액은 빨강이다. 억 단위 반올림으로 0인 경우에는 “유동성 증감을 항목별로 보면”으로 표시한다.

- 중앙 0 기준선을 점선으로 고정하고 좌우 축척을 동일하게 둔다. 왼쪽 음수는 빨강(흡수), 오른쪽 양수는 초록(방출). 합계는 마지막 행으로 구분한다.
- 세 주체는 순유동성 기여액의 절댓값 내림차순으로 정렬한다. 잔액 수준이나 부호로 정렬하지 않는다.
- 재무부·역레포 설명 아래에 비교 주차 잔액 → 선택 주차 잔액을 억 달러로 표시한다. 중복 잔액 카드는 제거한다.
- 연준은 자산 재조정의 유동성 방향을 먼저 쓰고 국채·기타 자산·MBS 증감을 모두 괄호에 표시한다. 0으로 반올림되는 항목은 생략한다. 흡수·방출·변화 없음에 따라 설명을 전환한다.

## 03 지급준비금 규모

- 기존 지급준비금 정의 문단 대신 선택 주차의 잔액과 명목 GDP 대비 비율을 표시한다. FRED GDP(분기·명목·계절조정 연율)를 백만 달러로 변환하며 다시 연율화하지 않는다.
- GDP 날짜는 분기 시작일이므로 종료일이 선택일 이하인 최신 분기를 사용한다. 분기와 지준 기준일을 함께 표시한다. 당시 공시 빈티지가 아닌 사후 수정치이며, 분기 종료 후 183일을 넘으면 비율을 표시하지 않는다.
- 월러 이사의 2025-07-10 발언상 GDP 대비 약 9%를 옅은 참고 설명으로 명시한다. 공식 안전선·연준의 합의된 임계값으로 쓰지 않으며 빠듯/넉넉 색 구간에 자동 적용하지 않는다.
