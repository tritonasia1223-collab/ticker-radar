# B안 국채 보유 구성과 발행사 참고치

생키 아래에서 전체 보유 구성 막대 → 같은 축의 발행사 비중 띠 → 금액 축 확대 막대로 연결한다.
서클·테더는 기존 해외·MMF 등과 중복될 수 있는 참고 집계이므로 전체 보유 주체의 새 조각으로 더하지 않는다.
색과 막대의 크기는 실제 금액으로 계산하며 최소 너비를 강제하지 않는다. 마우스 툴팁은 없다.

## 집계 기준

- 연준 Z.1 `F3.2.s` 공식 CSV, 백만 달러. 2010년부터 분기별 자료.
- 전체 구성비 분모는 `FL893061105.Q` 보유자 자산 합계. 시장성 국채 발행 잔액 `FL313161105.Q`와 평가·통계 차이가 있으므로 두 값을 혼동하지 않는다.
- 그룹 합계에 하위 항목을 재합산하지 않는다. 국내 헤지펀드는 기타에 포함, 해외 소재 펀드는 해외 부문에 포함.
- 서클: 월말 공시의 전용 펀드 국채 + 별도 계정 국채 공정가치. 레포·현금은 제외. 2025년 1월부터 2026년 8월까지 20개 월별 보고서.
- 테더: 분기 공시의 `U.S. Treasury Bills` 직접 보유 공정가치. 레포와 구성 확인이 안 된 간접 보유는 제외. 2025년 1분기부터 2026년 2분기까지 6개 보고서.
- 전체와 발행사 모두 같은 분기 말로 맞춘다. 월말 휴일 때문에 직전 영업일인 경우만 최대 7일 차이 허용. 일치하는 자료가 없으면 0이 아닌 결측.
- 발행사 합계 / 단기채 발행 잔액은 공정가치 / 액면가의 근사 비율이다. 전체 국채 비중과 구분해 표시한다.
- 상단 주차와 연동하되 관측일 기준의 사후 역사 조회를 사용한다. 이후 공시·수정된 자료도 허용한다. 공시일과 수집일을 보존한다.
- 서클 일간 종목 매칭에 의한 신규 매입 추산은 이 **보유액** 그래프에 사용하지 않는다. 미구현 추산을 공시 보유액처럼 표시하지 않는다.

## 갱신

설정: `shared/treasury-ownership-config.json`. 데이터: `shared/treasury-ownership-data.json`.

Python의 `pypdf`를 설치한 환경에서 `python script/collect-treasury-ownership.py` 실행.
공식 Z.1 전체 CSV와 서클의 2025년 이후 PDF 링크를 다시 읽는다. 테더의 새 분기 보고서는 설정의 `tetherReports`에 검증된 URL·관측일·공시일을 추가한다.
새 파일은 모든 파싱·합계 검증 성공 후에만 저장하며 오류 시 기존 파일을 유지한다. 원본과 추출 텍스트는 `tmp/treasury-ownership`에 남긴다.

현재는 검증한 공시 스냅샷을 앱에 포함한다. 자동 일간 수집 또는 주기적 배포가 연결된 상태는 아니다.
공시 갱신 주기: 연준·테더 분기, 서클 월간. 다음 공시 후 수집 명령과 검증을 실행해 배포해야 화면에 반영된다.
관측일과 선택 주차 차이가 190일을 넘으면 화면에서 추가 수집 필요를 알린다.
