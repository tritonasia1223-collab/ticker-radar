## 남은 범위

- 초안과 실패 큐는 메모리 기반입니다. 이탈 경고를 무시하거나 브라우저가 강제 종료되면 미저장 내용의 복구를 보장하지 않습니다. 로컬 복구 저장소는 별도 개선입니다.
- 여러 창의 동시 편집을 자동으로 병합하지 않습니다. 구조 저장 충돌 시 편집본을 유지하고 사용자가 서버본과 비교하도록 안내합니다. 노드 내용·메타 설정 등 모든 API에 버전 검사를 확대한 것은 아닙니다.
- World/Fed/Capitalism의 큰 페이지를 역할별로 분리하는 작업, 지도 자료의 지연 로딩, api·전체 운영 스크립트까지 타입 검사 확대는 후속 구조 개선입니다.
- 유동성 프로그램이 실제로 없던 과거라도 관측 근거가 없으면 ‘자료 부족’으로 취급합니다. 활성 기간을 출처와 함께 모델링하거나 자료를 보완하는 것은 후속 데이터 작업입니다. 운영 유동성 데이터의 최신성·외부 자료의 사실관계는 이번 합성 데이터 테스트로 검증되지 않습니다.
