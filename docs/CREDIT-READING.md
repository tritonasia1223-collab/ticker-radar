# B안 민간 신용 해설

B안은 A안과 같은 `/api/liquidity/credit?asOf=...&basis=observation&years=...` 응답을 사용한다. 원천 수집·신호·시나리오 임계값은 `shared/credit/credit_indicators.json`과 기존 분석 모듈을 공유한다. 데이터 수집을 추가하거나 복제하지 않는다.

- 상단: 유동성 문장형 리뷰(어디서 → 어디로)와 별도의 국채 리뷰. 산출 방법은 펼치기에 둔다. [리뷰 작성 규칙](LIQUIDITY-REVIEW-RULES.md)을 따른다.
- 신용 요약은 평시에는 확인된 범위를 한 문장으로, 주의 신호가 있으면 변화·크기·의미를 경고 문단으로 표시한다. 정상·미확인 조건이나 비은행 금융회사 대출 증가 단독으로는 경고하지 않는다. 조회 실패는 별도의 자료 상태로 표시한다.
- 안내성 서문은 생략하고, 본문에는 지표 정의·관측 해석·자료 한계를 유지한다.
- 06 은행 대출: 대출기준 → 수요 → C&I 잔액 → 대형·소형은행 → 비은행 금융회사 대출.
- 07 회사채: IG → HY → 발행량.
- 08 단기 자금: CP 스프레드 → CP 잔액.
- 09 취약 기업·사모대출: CCC → BDC P/NAV → 부실·PIK → 레버리지론 ETF 대용 지표.
- 10 함께 읽으면: 시나리오 후보, 일치·반대·부족 근거. 전체 적합도는 펼쳐보기.

편집 순서·일반 해설·관측값의 해석은 `shared/credit/reading.ts`, 화면과 조회는 `client/src/components/credit/CreditReading.tsx`에 둔다. 편집 목록은 기존 14개 지표를 정확히 한 번 포함하도록 검증한다.

## 왼쪽 챕터 종합 답변

- 챕터명 → 기존 질문형 정의 → 종합 의견 순서를 유지한다. 01~04는 옆 도표를 반복하는 의견을 생략하고, 05~10 의견은 테두리·말풍선 꼬리 없이 옅은 회색 블록으로 구분한다.
- 블록의 지표 정의·해석 한계는 12px의 옅은 글씨, 관측 분석·결론은 본문과 같은 14px로 표시한다. 문단 전체를 굵게 하지 않고 증감 금액과 결론의 핵심 구절 하나에만 중간 굵기를 적용한다. 증가·강화는 초록, 감소·약화는 빨강이며 좋고 나쁨의 판정색이 아니다. 정의·일반 설명·변화 없음·부정 및 가정 구절은 중립색으로 둔다. 문단 간격은 14px이며, 왼쪽 폭은 데스크톱 260~280px이다. 모바일에서는 본문 위로 쌓인다.
- 왼쪽 고정 위치는 ResizeObserver로 측정한 상단 바 높이 + 20px이다. 화면보다 긴 의견은 먼저 자연스럽게 스크롤한 뒤 하단이 보이는 위치에 고정한다. 최초 행 여백은 바깥에 둔다. 개요와 지표 이동 여백도 상단 바 기준을 공유하며, 상단 바가 고정되지 않는 모바일은 20px만 둔다.
- `shared/liquidity-chapters.ts`는 01~05의 수치·원인·행선지·입찰·자금시장 요약을, `shared/credit/chapter-reading.ts`는 06~10의 신용 요약을 만든다. 기존 원자료·설정을 재사용하며 수집이나 시나리오 임계값을 바꾸지 않는다.
- 은행: 실제 기업대출 잔액의 선택 기간 증감 + 최신 분기 대출기준·수요. 비상 인출과 소형은행 경고는 우선한다. 대출기준 순강화 비율이 낮아져도 양수라면 완화로 쓰지 않는다.
- 은행 보고서는 H.8 정의 → 실제 비교일의 잔액 변화 → SLOOS 정의 → 심사 태도·차입 수요 → 결론 순서다. 주어는 기업과 은행으로 명확히 쓰고 '문턱·규제' 대신 '심사 기준'을 쓴다. 순비율 수치와 설명은 의견 블록에서 생략하고 응답을 종합한 방향만 서술한다. SLOOS는 직전 분기와 비교하고 누락 분기를 이어 붙이지 않는다. 주간 관측이 선택 주차보다 늦으면 정확히 4주 변화라고 부르지 않고 실제 비교일을 쓴다.
- 회사채: 발행이 확인되면 조달이 이어진다는 사실과 시장금리 부담을 함께 쓴다. '안정' 임계값을 충족하지 않았다는 이유만으로 모든 관측을 판단 유보로 바꾸지 않는다. 전체 발행으로 등급별 접근성을 단정하지 않는다.
- 취약 기업: 급변·추세 경고와 별개로 선택 기간의 작은 추가 금리 변화도 서술한다. BDC·ETF의 경고는 사모대출 전체의 부실로 확대하지 않는다.
- 기존 '혼합 신호·조건 관측' 문단은 본문의 '요약 근거·세부 기준' 펼치기로 옮긴다. 관측일·조사 범위·자료 시차도 함께 둔다. 오류·결측·갱신 지연을 안정으로 표현하지 않는다.
- 검증: `tests/chapter-reading.test.ts`에서 기간 반전·결측·미세 악화·비상 인출·원인 상쇄를 확인한다.

## 날짜와 비교

선택 주차를 조회 키에 포함하며 다른 날짜의 이전 응답을 그대로 표시하지 않는다. 그래프·수치·해설이 동일한 응답을 사용한다. B안의 입찰 조회와 기존 스트레스·배경 자료도 선택일 이후 관측을 제외한다.

일간·주간 변화 문장은 상단 4주·13주 선택에 따른다. 월간·분기 자료는 직전 달·분기 관측과 비교하고, 중간 기간이 누락되면 비교 자료 부족으로 표시한다. 시나리오 조건은 A안의 고정된 4주·13주 등의 규칙을 그대로 사용하며 이를 화면에 명시한다.

현재 확보한 수정 자료를 관측 시점에 배치한 분석이다. 당시 알려진 정보만 재현하는 백테스트가 아니다. 분기 NAV 및 공시일, 관측 경과 일수를 보존한다. 과거 10년이 부족하면 확보 기간 백분위로 표시한다.

## 해석 제한

자료 없음·갱신 지연·수집 오류를 정상으로 해석하지 않는다. 회사채 전체 발행액을 IG·HY 발행량으로 대신하지 않는다. CP 비용 급등과 C&I 급증이 겹치면 비상 인출 해석을 우선한다. BDC 공시 기준과 ETF 대용 지표의 한계는 각 그래프에 표시한다. 적합도는 확률이 아니다.

검증: `npx vitest run tests/credit-reading.test.ts tests/credit-history.test.ts tests/credit-monitor.test.ts tests/liquidity-read.test.ts` 및 TypeScript 검사, 실제 화면의 주차·비교 기간 전환.

## 금리와 스프레드 표시

- CP·SOFR−IORB는 기본값으로 두 원금리를 동일한 % 축에 표시하고 사이만 중립색으로 칠한다. 토글로 차이만 표시하며 CP는 %p, SOFR−IORB는 bp를 사용한다.
- 날짜가 다른 관측은 차감하지 않으며 결측을 전일값으로 메우지 않는다. 교차 시 차이는 음수를 유지하며 음영 폭은 교차점에서 0이 된다. 기간과 선택 주차는 두 보기에서 같다.
- IG·HY·CCC는 시장금리(기본)와 공식 OAS를 전환한다. 시장금리는 각각 BAMLC0A0CMEY, BAMLH0A0HYM2EY, BAMLH0A3HYCEY로 JSON에서 정의하고 기존 일간 수집으로 갱신한다. OAS에서 임의 국채 금리를 역산하거나 특정 국채와의 차이를 OAS로 표시하지 않는다.
- 어느 보기에서나 시장금리와 프리미엄의 최신값·비교 변화·관측일을 함께 표시한다. 시장금리는 신규 발행·차환 여건의 참고치이며 기업 전체의 기존 평균 지급이자율이 아니다.
- 참고 원금리는 API의 comparisonLines로 반환한다. 기존 lines와 시나리오 규칙은 유지하므로 시장금리를 OAS 임계값에 넣지 않는다. 금리와 스프레드의 비교일이 다르거나 자료 오류·지연이 있으면 동반 방향 해석을 유보한다.
- 최근 3년만 제공되는 ICE 원천의 범위 밖은 자료 없음으로 표시하고, 확보 기간을 10년 백분위로 부르지 않는다.

## 급변과 별도의 완만한 악화

- `credit_indicators.json`의 `ccc_gap_trend.weeklyGapTrend`가 기준 원본이다. 초기값은 종료된 6주 동안 CCC OAS − HY OAS가 매주 0.01%p 이상, 누적으로 0.25%p 이상 확대되고 CCC OAS 자체도 상승하는 조건이다. 경험적 참고값이며 공식 기준이나 검증된 예측모형이 아니다.
- 선택일 이전에 끝난 금요일 주간의 공통 관측일만 사용한다. 휴장일은 같은 주 4일 이내에서 허용한다. 누락 주를 이어 붙이거나 서로 다른 날짜를 차감하지 않는다. 진행 중인 주·미래 관측은 제외한다. 4주·13주 비교 토글 및 차트 표시 기간과 독립적이다.
- 급변 조건 미충족과 추세 미충족을 금융시장 전체의 악화 부재로 표현하지 않는다. CCC 그래프 아래에 실제 격차 변화·연속 확대 주수·CCC 자체 변화와 사용 기간을 표시한다. HY에는 CCC가 포함되므로 두 독립 집단의 비교로 설명하지 않는다.
- 확인된 추세는 A/B 공통 신호, B안 그룹 해설 및 상단 경고에 반영한다. 시나리오 D의 CCC 조건은 급변 또는 추세 중 하나로 충족할 수 있지만 나머지 필수 조건도 충족해야 한다. 추세 경고가 있으면 ‘건강한 확장’ A 후보는 차단한다.

## 레버리지론 ETF 오독 방지

- 원자료는 BKLN·SRLN의 분배금·분할 수정가격이다. 원가격으로 임의 변환하지 않는다. 기본 차트는 ‘분배금 반영 성과 · 첫 관측 = 100’, 금액 표시는 ‘분배금·분할 수정가격’, 전환 버튼은 ‘수정가격 보기’로 쓴다.
- 차트 바로 아래에 ‘분배금 누적으로 상승할 수 있어, 우상향만으로 대출 가격이나 신용 여건이 개선됐다고 볼 수 없습니다’를 표시한다. 항상 우상향한다고 단정하지 않는다. 기존 급락 조건은 분배금 반영 수정가격 변화율에 그대로 적용한다.
- 공식 성과 정의 참고: [SSGA SRLN](https://www.ssga.com/us/en/institutional/etfs/state-street-blackstone-senior-loan-etf-srln), [Invesco BKLN](https://www.invesco.com/us/en/financial-products/etfs/invesco-senior-loan-etf.html).
- 검증: `tests/credit-trends.test.ts`와 기존 신용·리뷰 테스트. 설정 파일 변경으로 수집본의 configHash가 달라지므로, 운영 배포 시 새 설정의 수집 작업을 완료해 설정 변경 대기 표시를 해소해야 한다. 배포 전 현재 운영 DB의 설정 해시를 바꾸지는 않는다.
