# 세계 현황판 — 신규 탭 기획서

> 대상: 자본주의 경제사 신규 탭 `/#/world` (가칭)
> 스택 전제(교정): Vite + React + TS(기존) + **D3 지오(신규: d3-geo·d3-zoom·topojson-client)** + Express/Drizzle → Supabase. 프런트는 정적 TopoJSON을 직접 렌더(`/capitalism` 정적 JSON 선례와 동일), 큐레이션 데이터(항만·블록·분쟁)만 `/api/world` 경유. 외부 지도 API·타일 미사용. **Phase 1은 DB·API 불요**(전부 정적 TopoJSON). 상세 교정 근거는 §11.
> 용도: 본인 리서치용. 메인 니즈는 지리 문해력 — "이 나라가 어디 있고, 누구와 붙어 있고, 지금 어디서 전쟁이 나는지 눈으로 확인".
> 핵심 질문: **"지금 세계 어디서 무슨 일이 벌어지고 있고, 그곳이 지도 어디인가."**

## 0. 수록 기준 — 팩트 온리 원칙

이 탭의 모든 데이터는 **제3자 출처로 검증 가능한 사실**만 수록한다.

- 수록: 지리 좌표(국경·수도·항만·해협·항로), 공식 블록 가입 여부(NATO/EU/OPEC+/BRICS 등), 무력분쟁 진행 여부(당사국·시작일·출처).
- 배제: 국가별 서술·평가 텍스트("~좌장", "~전환 중" 류), 견제·관계 판정("A가 B를 견제"), 긴장 단계 같은 해석적 등급. → 전부 후속 확장(§9)으로 보류.
- 분쟁 상태값은 공식적으로 확인 가능한 것만: `무력분쟁 진행` / `휴전(협정 존재)` 2단계. "긴장"은 판정이므로 없음.
- 판별 테스트: **"이 값의 출처 링크를 달 수 있는가?"** 못 달면 안 넣는다. 분쟁 레코드에는 출처 URL 필드 필수.

## 1. 범위

**이번 구현 포함**: L1 국가 기본 / L2 무역 인프라 / L3 블록 / L4 분쟁 + 검색·팬줌·국가 카드.
**명시적 제외(후속)**: 견제·관계 엣지, 국가 서술 텍스트, 타임 스크러버(과거 재생). 단 §7 스키마의 `valid_from/valid_to`는 지금 넣는다 — 과거 확장을 "쿼리 조건 추가"로 만들기 위한 선투자.

## 2. 데이터 소스

| 데이터 | 소스 | 형태 | 갱신 |
|---|---|---|---|
| 국경·국가 속성(한글명 포함)·수도 좌표 | Natural Earth (퍼블릭 도메인) → TopoJSON 변환 | 정적 파일. 세계용 저해상 + 권역용 중해상 2종 | 사실상 없음 |
| 항만 (30~50개 큐레이션) | 직접 입력 | Supabase 테이블 | 최초 1회 |
| 초크포인트 (~10: 호르무즈·말라카·수에즈·파나마·바브엘만데브·보스포루스·지브롤터·타이완해협·베링·희망봉) | 직접 입력 | 〃 | 최초 1회 |
| 항로 (주요 동맥 + 북극항로) | 직접 입력 (좌표 폴리라인) | 〃 | 최초 1회 |
| 블록·가입국 | 공식 명단 기준 직접 입력 | 〃 | 변동 시 |
| 분쟁 목록 | UCDP/ACLED 등 공개 분쟁 DB 기준으로 수동 정리 | 〃 (출처 URL 포함) | 주간 점검 |

국경 표기 기준: 실효 지배(Natural Earth 기본값)로 확정.

## 3. 레이어 구조와 토글 규칙

| 층 | 시각 채널 | 토글 | 기본값 |
|---|---|---|---|
| L1 국가 기본 (국경·라벨·수도) | 윤곽선 + 텍스트 + 점 | 없음(상시) | 켜짐 |
| L2 무역 인프라 (항만·초크포인트·항로) | 점·다이아몬드·점선 | 독립 온오프 | 켜짐 |
| L3 블록 | 면 채색 (블록 선택 드롭다운: NATO/EU/OPEC+/BRICS…) | 면끼리 상호 배타 | 꺼짐 |
| L4 분쟁 | 면 채색 (진행=적 400 계열, 휴전=적 100 계열) | 면끼리 상호 배타 | 꺼짐 |

- 면(L3·L4)은 동시에 하나만 — 같은 채널(국가 채색)을 두 층이 쓰면 섞이므로.
- 선·점(L2)은 어느 면 위에도 겹침 가능 (예: 분쟁 채색 + 항로 = 홍해 상황 뷰).
- 선택 하이라이트(청록)는 층이 아니라 상시 인터랙션 — 항상 최상위.

## 4. 시각 사양

- **표면 토큰 지도**: 바다 = 페이지 배경 톤, 땅 = 카드 표면 톤, 국경 = 헤어라인. 기본 상태는 무채색에 가깝고 색은 상태만 발화.
- **색 신원**: 선택국 = 청록 / 인접국 = 청록 30% / 초크포인트 = 앰버 다이아몬드 / 항로 = 파랑 점선 / 항만 = 파랑 점 / 분쟁 = 적 램프 2단 / 블록 = 층별 단일 범주색. 유동성 탭과 동일 팔레트 체계.
- **투영**: Equal Earth (면적 왜곡 없음 — 지리 감각 학습 목적에 부합). 메르카토르 금지.
- **시맨틱 줌 3단**:

| 단계 | 줌 배율(안) | 표시 |
|---|---|---|
| 세계 뷰 | 1~2.5x | 대국 라벨만, 초크포인트, 항로 |
| 권역 뷰 | 2.5~6x | 전 국가 라벨 + 수도 점·이름, 항만 점 |
| 국지 뷰 | 6x~ | 항만 이름, 해협 이름까지 |

- 라벨은 전부 한글. 라벨 충돌 시 면적 큰 나라 우선.

## 5. 인터랙션

- **팬/줌**: 드래그 팬, 휠·버튼(±) 줌, 더블클릭 줌인. d3-zoom. 줌 범위 클램프(세계 뷰 밖으로 축소 불가).
- **권역 프리셋**: 중동/아프리카/남미/동남아/유럽 버튼 → 해당 바운딩박스로 애니메이션 플라이투.
- **검색**: 클라이언트 사이드. 색인 = 국가(한글 정식명·통칭·영문명·별칭) + 항만 + 초크포인트, 유형 뱃지로 구분. 부분 일치, 정규화(공백·대소문자 무시). 선택 시 해당 대상으로 플라이투 + 선택 상태 진입. 별칭 열은 관심 권역부터 채움. 초성 검색은 후속.
- **국가 선택**: 클릭 → 청록 채색 + 인접국 옅은 청록 + 국가 카드 오픈. 빈 바다 클릭 = 선택 해제.
- **국가 카드 (팩트 필드만)**: 국명(한/영) · 수도 · 소속 블록 뱃지 · 분쟁 뱃지(진행 중이면 상태+시작일+출처 링크) · 인접국 칩. 인접국 칩 클릭 = 그 나라로 선택 이동(체이닝). 서술 텍스트 필드 없음.
- **hover**: 국가 옅은 하이라이트 + 이름 툴팁 (라벨 생략된 소국 대응). 초크포인트·항만 hover 시 이름+한 줄 팩트(연결 수역 등).

## 6. 화면 구성

풀블리드 지도 캔버스 + 플로팅 컨트롤 4개: 검색(좌상) · 층 토글 칩(우상) · 권역 프리셋(좌하) · 줌 ±(우하). 국가 카드는 우측 플로팅(카드 스타일은 유동성 탭과 동일 토큰). 그 외 상시 UI 없음.

## 7. 스키마 (Supabase)

```
countries      — 정적 파일(TopoJSON 속성)로 갈음. DB에는 별칭만: country_aliases(iso, alias)
ports          (id, name_ko, name_en, lat, lng, note)
chokepoints    (id, name_ko, name_en, lat, lng, connects)      // connects: "페르시아만↔오만만"
routes         (id, name_ko, coords jsonb)
blocs          (id, name, color_token)
bloc_members   (bloc_id, iso, valid_from, valid_to)
conflicts      (id, name_ko, parties iso[], status enum(active, ceasefire),
                started_on, valid_from, valid_to, source_url NOT NULL)
```

- `valid_from/valid_to`: 현재 화면은 `valid_to IS NULL`만 조회. 과거 확장 시 날짜 조건으로 전환.
- `source_url NOT NULL` — §0 팩트 원칙의 스키마 강제.

## 8. 구현 순서

1. **Phase 1 — L1**: TopoJSON 파이프라인(변환 스크립트 포함), Equal Earth 렌더, 팬/줌, hover, 국가 선택+인접국 하이라이트, 국가 카드(수도·인접국만), 시맨틱 줌 1차(라벨 단계). *이것만으로 메인 니즈 충족 — 여기서 1차 배포.*
2. **Phase 2 — 검색 + 프리셋**: 색인·별칭, 플라이투.
3. **Phase 3 — L2**: 항만·초크포인트·항로 입력과 렌더, 독립 토글.
4. **Phase 4 — L3·L4**: 블록·분쟁 테이블, 면 토글(상호 배타), 국가 카드에 블록·분쟁 뱃지 결합.

## 9. 후속 확장 (이번 범위 아님)

- 견제·관계 엣지: "관계 보기" — 국가 선택 시 부챗살 엣지 + 텍스트 서사. 해석 데이터라 큐레이션 워크플로 설계와 함께.
- 국가 서술 텍스트: 관심 권역 30~40개국부터.
- 타임 스크러버: §7의 valid 기간 필드가 전제. 달러 패권사 타임라인 이벤트 DB와의 연결 검토.
- 초성 검색.

## 10. 미결 사항

1. 라우트명·탭 표기 확정 (`/#/world`, "세계 현황판" 가안).
2. 항만 큐레이션 목록 (30~50개 선정 — 트리톤 작성).
3. 분쟁 목록 초기 시드와 주간 점검 루틴(어느 요일에 UCDP/ACLED 대조할지).
4. 권역 프리셋의 바운딩박스 5개 좌표.

## 11. 구현 스택 교정 (우리 레포 기준)

기획서 §0~§9의 **기능 설계는 그대로 유효**하다. 아래는 실제 레포(React18+Vite+TS / wouter 해시라우트 / react-query / shadcn / Tailwind / **Recharts** / Express5+Drizzle→Supabase 세션풀러)와 맞추기 위한 교정만.

1. **D3 지오 = 유일한 순수 신규 의존성.** 현재 차트는 전부 Recharts고 Recharts엔 지리 투영이 없다. `d3-geo`(`geoEqualEarth` 포함)·`d3-zoom`·`topojson-client` 3종을 새로 추가한다.
   - **`/world` 라우트 `React.lazy` 코드스플릿 필수**(App.tsx 기존 패턴). d3+TopoJSON이 초기 번들을 오염시키지 않게 — `/capitalism`(357KB JSON+framer)이 이미 이 방식.
   - **렌더는 Phase 1 SVG**(저해상 세계 ~200 path는 per-country 클릭/hover가 SVG로 가장 단순). 권역 중해상(50m)까지 확대 붙일 때 성능 이슈 나면 그때 Canvas + `d3.geoContains` 히트테스트로 국지 전환 검토.
2. **데이터 접근 = Supabase 직접 아님.** 프런트는 Supabase를 직접 치지 않고 **Express `/api/world/*` + `server/world.ts` + Drizzle**로 나가 react-query로 소비(`server/capitalism.ts`·`/api/capitalism/*` 선례 그대로). **단 Phase 1은 DB·API 자체가 불요** — 국경·한글명·수도·인접국이 전부 정적 TopoJSON에서 나온다. DB/api는 Phase 3·4에서 처음 도입.
3. **DDL은 raw 스크립트로만.** 공유 Supabase에 `drizzle-kit push` 절대 금지(#26 — 미선언 테이블 DROP CASCADE 위험). 테이블은 `script/db-push-world.ts`(CREATE TABLE IF NOT EXISTS)로 생성, 타입용으로만 `shared/schema.ts`에 선언.
4. **테이블 네이밍 `world_*` 접두어**(cap_* 관례): `world_ports` · `world_chokepoints` · `world_routes` · `world_blocs` · `world_bloc_members` · `world_conflicts` · `world_country_aliases`. §7의 무접두어(ports/routes)는 제네릭 충돌 위험이라 교체.
5. **postgres.js 주의**: lat/lng 집계 시 `::float8` 캐스트 습관 유지. `parties iso[]`·`coords jsonb`는 정상 반환.

## 12. Phase 1 착수 플랜 (DB 없이 · 1차 배포까지)

목표: **정적 TopoJSON만으로 L1(국경·라벨·수도·팬줌·국가선택·인접국·국가카드) 완성 → 배포.** 서버·DB 변경 0.

**선결(코딩 전 확정할 데이터 3개)**
- (a) **한글 국명 소스**: Natural Earth admin-0의 `NAME_KO` 필드 유무 확인 → 있으면 그대로, 없으면 `iso_a3 → 한글명` 매핑 테이블(정적)로 보강.
- (b) **해상도**: 세계=110m(저), 권역 확대용 50m(중)은 Phase 1 선택(우선 110m만으로 배포 가능).
- (c) **수도 좌표**: admin-0 label point vs `ne_10m_populated_places`(수도) 중 택1.

**작업 순서(커밋 경계 = 각 번호)**
1. **의존성**: `d3-geo` `d3-zoom` `topojson-client`(+ `@types/*`) 추가. 변환은 dev-time `mapshaper`(또는 topojson CLI)로 오프라인 처리.
2. **TopoJSON 파이프라인** `script/build-world-topo.ts`: Natural Earth admin-0 → 속성 트림(iso_a3·name_ko·name_en·면적·label point만) → `client/src/data/world-110m.json` 산출. 재현 가능한 변환 스크립트로 커밋(원본 shp는 gitignore).
3. **라우트/네비**: App.tsx `const World = lazy(() => import("@/pages/World"))` + `<Route path="/world" component={World} />`; Layout.tsx NAV에 "세계 현황판"(lucide `Globe`).
4. **렌더 코어** `client/src/pages/World.tsx`: `geoEqualEarth()`+`geoPath()`로 SVG `<path>` per country. 표면 토큰(바다=페이지 배경 / 땅=카드 표면 / 국경=헤어라인)은 유동성 탭과 동일 Tailwind CSS 변수 재사용 → 라이트/다크 자동.
5. **팬/줌**: `d3-zoom` 드래그·휠·더블클릭 + 버튼 ±, 줌 범위 클램프(세계 뷰 밖 축소 불가).
6. **인터랙션**: hover(옅은 하이라이트+이름 툴팁, 라벨 생략 소국 대응) · 클릭 선택(청록) · `topojson.neighbors(objects)`로 인접국 옅은 청록 · 빈 바다 클릭 해제.
7. **국가 카드(팩트 필드만)**: 국명(한/영) · 수도 · 인접국 칩(클릭 = 그 나라로 체이닝). 블록·분쟁 뱃지는 Phase 4 결합 자리만 비워둠(우측 플로팅, 유동성 탭 카드 토큰).
8. **시맨틱 줌 1차**: 줌 배율 구간(세계=대국 라벨만 / 권역=전국 라벨+수도점 / 국지=…)으로 라벨 노출 제어, 충돌 시 면적 큰 나라 우선.
