# 그래프 비교(베타)

경로 `/#/graph-compare`. 사이드바에서 **자본주의 경제사 바로 아래**에 있는 독립 페이지입니다.

## 사용법

1. 기본 달러 접합지수·원/달러·엔/달러 또는 원하는 기존 경제사 지표를 선택합니다.
2. 기준월=100으로 최대 4개, 원래 값/좌우 축으로 최대 2개를 비교합니다. 원래 값으로 전환할 때 앞의 2개만 남깁니다.
3. 날짜 입력이나 아래 탐색 막대의 양 끝으로 구간을 확대하고, 선택 영역을 밀어 이동합니다. 기준월은 구간 이동에 따라 바뀌지 않습니다.
4. **사건 가져오기**에서 카드를 펼쳐 내부 노드를 선택합니다. 여러 카드의 노드를 가져올 수 있습니다.
5. 가져온 사건 목록에서 노드를 선택하고 시작일·선택적 종료일을 직접 지정합니다. 날짜가 없으면 미배치 목록에 남습니다.
6. 날짜가 있는 노드는 그래프 위 사건 띠에 표시됩니다. 원본 카드별 행을 만들고 제목이 겹치면 하위 줄로 배치합니다.
7. 선택한 사건은 그래프에서 강조하고, **이 사건 구간 보기**로 주변을 확대합니다. 원문·메모·표를 확인하고 **원본 카드**로 이동할 수 있습니다.

## 큰 흐름 · 국면 · 시대적 사건

- **원본 / 큰 흐름** 토글은 선에 표시할 관측점만 줄입니다. 3·6·12·24개월 달력 구간마다 실제 최고·최저 관측값의 원래 날짜를 남기고 직선으로 연결합니다. 구간 내 작은 굴곡은 생략하므로 모든 국소 고저점을 보존하는 것은 아닙니다. 표시 구간의 양 끝과 각 결측 구간의 경계도 남깁니다.
- 두 모드의 기준월 정규화는 동일하게 `원래 관측값 / 기준월 원래 값 × 100`입니다. 세로축도 생략 전 전체 관측값으로 계산하여 전환 시 유지합니다. 툴팁은 생략한 월도 실제 값을 보여 줍니다. 결측은 연결하지 않으며, 시작 구간을 평균 계산 때문에 잘라내지 않습니다. 초기 이동평균 방식에서 고점이 낮아지고 늦어지던 문제를 이 방식으로 교체했습니다.
- **국면 배경**은 선택한 기준 지표의 대략적인 상승·하강 경향입니다. 12개월 이동평균을 6개월 전과 비교하고, 두 평균의 절댓값 중 큰 값의 1%보다 큰 변화가 있을 때 방향을 바꿉니다. 그 안의 작은 변화는 직전 방향을 유지하고 최초에는 방향 미정입니다. 충분한 자료가 없거나 결측 구간이면 배경도 비웁니다.
- 국면 계산은 표시 구간·기준월·선의 단순화 구간과 독립적입니다. 기준 지표가 선택 목록에서 빠지면 첫 지표로 전환합니다. 상승은 해당 지표의 수치 상승이며 호황·자금 유입·달러 강세 등을 일괄 판정하는 의미는 아닙니다. 평균을 사용하므로 실제 변곡보다 늦게 전환될 수 있습니다.
- **경제사 카드 표시**는 유효한 날짜가 있는 기존 카드의 제목을 같은 시간축에 표시합니다. 화면상 가까운 사건은 묶고 확대하면 나뉩니다. 클릭하면 해당 카드 목록·노드 본문·메모를 읽고 원본으로 이동할 수 있습니다. 원인을 자동 작성하거나 사건 날짜를 재해석하지 않습니다.
- 자동으로 표시한 경제사 카드와 직접 가져와 날짜를 지정한 노드 배치는 별도입니다. 경제사 카드를 숨겨도 직접 배치한 사건은 유지됩니다.

## 데이터와 해석

- 원/달러: [FRED EXKOUS](https://fred.stlouisfed.org/series/EXKOUS), 원/1달러, 월평균, 1981-04~2026-08.
- 엔/달러: [FRED EXJPUS](https://fred.stlouisfed.org/series/EXJPUS), 엔/1달러, 월평균, 1971-01~2026-08.
- 위 두 환율의 상승은 달러 강세/상대 통화 약세입니다. 미완료 월은 수록하지 않습니다.
- 기존 달러 계열은 주요통화 명목지수와 BIS 광의 명목지수의 접합 계열입니다. 공식 DXY로 표시하지 않습니다.
- 원래 발표된 월간·분기 값은 유지하고, 일·주간 자료는 각 월 마지막 관측값을 사용합니다. 원래 관측일은 툴팁에 표시합니다. 결측을 채우거나 결측 구간을 선으로 연결하지 않습니다.
- 기준월에 모든 지표의 양수 값이 없으면 요청월 이후 첫 공통 양수 월을 명시하여 적용합니다. 공통 기준값이 없으면 변환 그래프를 표시하지 않고 기준·지표 변경 또는 원래 값 사용을 안내합니다.
- 기준월=100은 선택한 월 대비 상대 변화입니다. 지표의 경제적 의미가 같아진다는 뜻은 아닙니다. 실질 순수출은 2017년 연쇄달러·계절조정 연율, 인플레이션은 CPI 수준이 아닌 전년 대비 변화율입니다.
- 월간 갱신은 기존 `script/fetch-capitalism-series.ts`/GitHub Actions에 연결됩니다. 계열 로더의 공용 청크 분리도 배포 검증기가 추적합니다.

## 원본과 저장

- 원본을 복사하거나 분해하여 수정하지 않습니다. `flowSlug + nodeKey`를 참조하고 연표용 제목·날짜만 별도로 저장합니다.
- 원문 수정은 반영됩니다. 원문이 삭제되어도 배치를 보존하고 **원본 없음** 상태를 표시합니다. 배치 제거는 원본을 삭제하지 않습니다.
- 공용 보드 1개이며 노드마다 `plot:<uuid>` 협업 리소스를 사용합니다. 기존 `cap_settings`의 `comparison_node:<uuid>` 키에 저장하므로 추가 DDL은 필요하지 않습니다.
- 변경은 기존 협업 엔진/변경 이력으로 처리합니다. 다른 배치는 독립 저장, 같은 배치의 다른 필드는 병합, 같은 필드는 충돌 선택 대상입니다. 삭제는 버전 있는 null 문서를 남겨 다른 창에 전달합니다.
- 제목·날짜는 blur에서 확정합니다. 날짜 입력의 중복 포커스 이벤트가 편집 잠금을 누적하지 않도록 공통 포커스 훅을 보완했습니다.
- 지표 선택·기준월·확대 범위·단순화·국면 기준·경제사 표시 여부는 브라우저의 개인 보기 설정입니다. 탐색은 서버에 저장하지 않습니다. 발표 모드에서도 탐색할 수 있으며 배치 수정은 숨깁니다.
- 새 API: `GET /api/capitalism/collab/comparison`. 기존 `resource`, `edit`, `state`가 `plot:`을 지원합니다. 기존 경제사 서버 쓰기는 유지합니다.

## 검증 (2026-09-14)

- 계산/날짜/결측/서버 변경 경로 테스트와 기존 회귀 테스트.
- 임시 PostgreSQL 스키마에서 실제 트랜잭션: 배치 생성, 독립 필드 동시 병합, 잘못된 기간 롤백, 삭제 버전 및 원본·메타 보존. 생성한 테스트 스키마만 제거했습니다.
- Playwright, 합성 API 응답: 노드 가져오기, 날짜 지정, 타이핑 중 무저장·blur 저장, 범위 탐색 중 무저장, 새로고침 복원, 같은 필드 충돌 및 선택, 두 창 동기화, 원본 이동, 원문 변경/삭제 표시, 배치만 삭제.
- blur 없이 페이지가 전환되어도 입력 중 제목이 확정되는 것을 확인했습니다. 고저점 보존·국면 계산을 포함한 단위·회귀 테스트는 95개 통과했습니다.
- 편집/발표 전환 및 1280·1366·1920px 창에서 탐색. 실제 외부 모니터 연결은 별도 사용자 환경 확인 대상입니다.
- 큰 흐름 4개 기간, 원래 값/지수 전환, 국면 기준 지표 제거 시 대체, 사건 클릭·키보드 열람, 표시 숨기기, 새로고침 복원과 탐색 중 서버 편집 요청 0건을 확인했습니다.
- 원/달러 급등락 구간(1987~2005)에서 두 축 모드 × 단순화 구간 4개를 대조해 실제 SVG의 고점·저점 좌표, 축 눈금, 툴팁이 일치하고 생략 후 좌표가 전부 원래 관측점임을 확인했습니다.
- 운영 연구 데이터에 테스트 배치를 쓰지 않았습니다.
