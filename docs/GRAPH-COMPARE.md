# 그래프 비교(베타)

## 2026-10-23: 카테고리별 임시 숨김

- 지표 선택의 **달러·환율**, **경제·무역** 밑줄 버튼으로 해당 카테고리의 선택 지표를 숨기고 다시 표시합니다. 선택 목록과 숨김 상태를 분리해, 다시 표시할 때 미선택 항목은 켜지지 않습니다.
- 숨겨진 항목은 체크를 유지하고 흐리게 표시합니다. 두 카테고리는 독립적으로 조작할 수 있으며 숨김 상태도 브라우저 보기 설정에 저장합니다.
- 시간 범위와 인사이트 관련 지표는 임시 숨김으로 변경하지 않습니다. **전체 선택 해제** 및 인사이트의 **관련 그래프 보기**는 숨김 상태를 초기화합니다. 서버·운영 인사이트 데이터는 변경하지 않습니다.
- 검증: 타입 검사·관련 테스트 8개·빌드 통과. 로컬 브라우저에서 두 카테고리 독립 숨김/복원, 선택 부분집합 보존, 전체 숨김, 새로고침, 숨긴 상태의 개별 선택 수정, 전체 해제 및 390px 배치를 확인했습니다. 사용자의 운영 배포 요청에 따라 반영합니다.

## 2026-10-01: CPI 수준 → 달러 구매력

- 사용 목적에 맞게 CPI 수준 선택 항목을 **달러 구매력(미국 내, CPI 역수)** (`usd_purchasing_power`)로 교체했습니다. 공식 `CPIAUCNS`는 원자료로 유지하고, 공통 로더에서 **10000 / CPI**를 계산합니다(원래 값: 1982~1984=100). 월간 CPI 갱신이 곧바로 반영되며 원자료·DXY·REER는 변경하지 않습니다.
- 비교 차트에서 기준월=100으로 맞추면 **기준월 CPI / 해당 월 CPI × 100**입니다. CPI 100→125일 때 구매력 100→80. 결측·0·음수는 채우지 않고 제외합니다. 양쪽 탭·커서·구간 요약 모두 구매력 값을 사용합니다.
- 개인 보기 설정의 CPI 선택은 구매력으로 전환합니다. 저장된 인사이트·경제사 글의 CPI 참조는 의미를 바꾸지 않고 ‘CPI 수준(이전 지표)’로 표시하여 사용자가 다시 연결하게 합니다.
- 타입 검사·테스트 341개 통과. 아래 CPI 수준 추가 설명은 수정 이전 기록입니다.

## 2026-10-01: 명목·실질 달러 지표 분리

기존 `dollar`(Fed Major → BIS 명목 접합)를 제거하고 아래 세 지표를 양쪽 탭에 추가했습니다. 아래의 기존 달러 접합 설명은 교체 이전 기록입니다.

| 표시명 / 키 | 자료·수록 기간 |
| --- | --- |
| 달러지수(DXY, 명목) / `dxy` | Yahoo `DX-Y.NYB` 실제 INDEX, 1973-03부터 일간 종가의 월말 값 |
| 실질실효환율(REER, 장기 접합) / `reer` | 1973-01~1993-12 Fed `TWEXBPA` 조정값, 1994-01부터 BIS `RBUSBIS` 원자료 |
| 미국 소비자물가지수 (CPI 수준) / `cpi_level` | FRED `CPIAUCNS`, 1913-01부터, 비계절조정·1982~1984=100 |

- DXY는 월간 조회(1985년부터)가 아닌 **일간 조회**에 있는 과거 자료를 사용합니다. 거래소 현지 날짜로 월말을 고르며 미완료 월·결측은 제외합니다. 지수 코드와 `INDEX` 유형을 검증하고 선물·ETF·Fed 지수로 대체하지 않습니다. 1973-03 월말 값 101.17은 지수 기준시점=100과 별개입니다.
- REER 배율은 1994-01 BIS 88.66 / Fed 91.3648 = **0.9703956009316498**. 이전 252개월에만 곱해 소수 셋째 자리로 반올림하고 BIS 구간은 그대로 둡니다. 첫 12개 겹침 월의 비율 최대/최소=1.006712. 이 조정은 두 기관의 바스켓·가중치 차이를 없애지 않습니다.
- CPI는 구매력 자체가 아닌 물가 수준입니다. 상승하면 고정된 달러의 국내 구매력이 하락합니다. 기존 CPI YoY는 별도로 유지합니다.
- 신규 기본 표시를 세 지표로 변경했습니다. 기존 개인 설정에서는 `dollar`만 제외합니다. 기존 인사이트·경제사 글의 `dollar` 참조는 ‘기존 달러지수(삭제됨)’으로 표시하고 사용자가 다시 선택하게 합니다. DXY/REER로 자동 치환하거나 공용 글을 수정하지 않습니다.
- 초기 수집: CPI 1,363개(~2026-08), DXY 643개(~2026-09), REER 643개(~2026-07). 다른 25개 시계열은 전부 동일합니다. 최초 교체 스크립트는 `script/replace-dollar-indicators.ts`이며 이미 교체됐으면 덮어쓰기를 거부합니다. 백업·원자료 해시·비율 검증은 `script/cap-export/dollar-indicators-migration.json`에 남깁니다. 이후 기존 월간 갱신이 세 지표를 append-only로 갱신합니다.
- 검증: 타입 검사·테스트 340개·빌드 통과. 실제 소스로 월간 갱신 재실행 시 추가·변경 0개. 로컬 브라우저에서 세 지표 겹치기, 양쪽 탭 출처, 390px 배치, 옛 개인 설정·인사이트의 삭제 지표 처리를 확인했습니다.

## 2026-10-01: 구간별 원자료 설명

- 하단 출처 영역과 경제사 차트 확대 화면에서 **사용 기간 → 원자료 이름·링크 → 연결 방식**을 표시합니다. 선택 목록의 설명에도 기간과 원자료 이름을 표시합니다. 관측값과 차트 계산은 변경하지 않았습니다.
- 화면 설명은 기간·지표명과 짧은 조정 여부만 남깁니다. 시리즈 코드는 출처 링크에 마우스를 올려 확인하며 상세 계산·대조 이력은 이 문서에 보관합니다.
- 달러지수는 **1973-01~2019-12 연준 주요통화 명목지수 TWEXMMTH**, **2020-01부터 BIS 광의 명목지수 NBUSBIS 기반 연결값**입니다. BIS 자료는 1994년부터 있지만 사이트의 전환 시점은 2020년입니다. 과거 구간을 BIS로 역산한 것이 아니며 ICE DXY도 아닙니다.
- 원자료 대조에서 달러의 2019년 이전 564개 값은 TWEXMMTH를 소수 둘째 자리로 반올림한 값과 모두 일치했습니다. 2020년 이후는 현재 BIS 원자료 수준과 다릅니다. 초기 저장분의 환산식은 이력에서 확인되지 않아 단일 배율로 재현된다고 설명하지 않습니다. 월간 갱신 코드는 기존 값을 보존하고 새 관측값에 최근 겹침 최대 12개 저장값/원자료 비율의 중앙값을 곱합니다. 전환 경계에는 출처·계산 기준 차이가 반영될 수 있습니다.
- 정부부채는 1929~1938년 자체 비율 계산, 1939~1965년 GFDGDPA188S 연간, 1966년부터 GFDEGDQ188S 분기로 구분합니다. 연간 27개·분기 241개 저장값을 각 원자료와 대조했습니다.
- 금은 1833~1959년 연평균을 각 월에 반복한 구간, 1960년부터 월간 자료입니다. 1944년은 초기 수록 시작점이며 실제 주기 전환점이 아닙니다. 다른 과거 확장 지표도 현재 원자료까지 명시합니다.

## 2026-10-01: 지표 선택 간소화

- **표시할 지표 선택** 문구 바로 옆의 **전체 선택 해제**로 표시 지표를 한 번에 끕니다. 선택이 없으면 버튼은 비활성화됩니다. 인사이트·기간·스프레드 설정은 유지합니다.
- 보기 방식·지표별 축·오른쪽 단위 선택 메뉴를 제거하고 **왼쪽 기준월=100 · 오른쪽 실제 값**으로 고정했습니다. 이전 개인 설정과 인사이트 복원에도 자동 배정을 적용하며 지표 목록·기준월은 유지합니다.
- 오른쪽은 마지막에 체크한 오른쪽 지표의 단위를 자동 사용합니다. 다른 단위는 체크를 유지한 채 범례에 ‘대기’로 표시하고 짧게 안내합니다. 대기 지표를 껐다 켜면 그 단위로 전환됩니다. 선택을 해제하면 남은 오른쪽 지표 중 마지막 지표로 전환합니다. 단위 설명은 차트의 축 제목에 표시합니다.
- 미국 수출·수입 증가율, 실질 순수출, 수출−수입 증가율 격차의 숨김 변경은 취소했으며 네 지표를 계속 선택할 수 있습니다.

## 2026-09-30 개편: 자동 좌우 축 배정

기본 보기는 **왼쪽 기준월=100 · 오른쪽 실제 값**입니다. 아래 과거 설명과 충돌하는 경우 이 절을 우선합니다.

| 기본 축 | 지표 | 비교 기준 |
| --- | --- | --- |
| 왼쪽 | 달러지수, 원·엔·유로 환율, 주가지수·시가총액, 금·유가, 통화량·연준 유동성 | 왼쪽 지표의 공통 기준월=100 |
| 오른쪽 | 금리, GDP 성장률, 물가상승률, 실업률, GDP 대비 정부부채, 수출·수입 증가율 | 실제 % |
| 오른쪽 | 수출−수입 증가율 격차 | 실제 %p |
| 오른쪽 | 미국 무역수지 / 실질 순수출 | 각각 명목 월간 값 / 실질 연율 값 |

- 지표 선택에서 각 지표의 왼쪽·오른쪽 배정을 바꿀 수 있습니다. 음수뿐인 계열 등 양수 기준값을 찾을 수 없는 지표는 왼쪽 지수화가 불가능합니다. 한 지표를 표시할 수 없어도 유효한 다른 지표는 유지합니다.
- 같은 단위의 오른쪽 지표는 하나의 실제 값 축을 공유합니다. 예를 들어 금리 세 개를 동시에 표시합니다. 오른쪽에는 0 기준선을 표시합니다.
- 단위가 여러 종류면 **오른쪽 축 단위** 선택기로 전환합니다. 다른 단위의 지표는 체크를 유지한 채 ‘대기’로 표시합니다. 새 오른쪽 지표를 체크하면 해당 단위를 활성화합니다. 금리와 무역수지, 명목 무역수지와 실질 순수출을 같은 눈금에 섞지 않습니다.
- 왼쪽 기준월 계산에는 오른쪽 지표를 포함하지 않습니다. 환율 여러 개와 음수인 무역수지를 함께 켜도 원래 값 2개 모드로 강제 전환하거나 선택을 삭제하지 않습니다.
- 좌우 축 확대·축소는 독립적입니다. 지표 구성이 바뀐 축만 자동 맞춤으로 돌아가며, 오른쪽 단위를 바꿔도 왼쪽의 수동 축척을 유지합니다. 기준월 변경이나 ‘세로축 자동’은 수동 축척을 초기화합니다.
- ‘모두 기준월=100’과 ‘원래 값 · 좌우 2개’도 별도 보기로 남깁니다. 혼합 보기와 모두 지수화 보기에는 지표 개수 제한이 없습니다.
- 새 인사이트는 **현재 실제로 그려진 지표**와 스프레드, 보기 방식·요청 기준월·축 배정·오른쪽 단위를 `context.view`에 저장합니다. 단위 전환을 기다리는 지표는 포함하지 않습니다. 관련 그래프 복원은 이 설정과 글의 기간을 함께 불러옵니다. 수동 세로축 범위는 저장하지 않습니다.
- 기존 인사이트의 지표 연결은 그대로 읽으며 축 정보가 없는 글은 기본 혼합 배정으로 복원합니다. 새 개인 설정 키는 `comparison-view-v3`이며 v1/v2의 선택 지표·기간·기준월을 이어받아 혼합 보기로 시작합니다. 서버와 프론트엔드를 함께 배포해야 새 `context.view` 저장이 가능합니다.

검증: 타입 검사·전체 테스트 325개·프로덕션 빌드 통과. 실제 수록 시계열과 합성 협업 API로 4개 환율+무역수지, 금리 3개 공통 축, 오른쪽 단위 전환·수동 배정·새로고침, 축 정보가 없는 이전 글과 새 글의 설정 저장·복원, 오른쪽 축 확대 시 왼쪽 값 유지, 390px 배치와 다크 모드를 확인했습니다. 운영 데이터에는 테스트 글을 저장하지 않았습니다.

## 2026-09-21 개편: 차트와 시간 기준 인사이트

현재 화면은 차트를 중심에 두고 왼쪽에 선택·이동 / 날짜 기록 / 기간 기록 도구, 오른쪽에 **인사이트 / 경제사 참고** 사이드바를 둡니다. 아래의 기존 사용법은 9월 14일 버전의 기록이며, 현재 동작은 이 절을 기준으로 합니다.

### 읽기와 쓰기 중심 배치

- 오른쪽은 경제사 별표 인사이트와 같은 작은 날짜 → 빨간 별·14px 제목 → 구분선 → 14px/22px 본문 순서입니다. 본문 입력칸은 내용에 맞춰 높이가 늘어납니다.
- 날짜 편집과 관련 그래프·짧은 차트 설명·삭제 설정은 필요할 때 펼칩니다. 저장 상태와 변경 이력은 상단에 유지합니다.
- 차트 배지는 선택 시 채운 빨간 별, 비선택 시 윤곽 별을 사용합니다. 선택 구간과 안내선, 짧은 설명의 강조색도 빨강으로 맞춥니다.
- 커서 값은 차트 상단, 구간 요약은 차트 하단에 표시합니다. 차트 높이는 요약과 탐색 버튼의 실제 높이에 맞춥니다.

### 인사이트 작성과 열람

- **배지 하나 = 글 하나**입니다. 제목·시작일·선택적 종료일·자유 본문·선택적 차트 설명을 저장합니다. 위치는 시간 기준이며, 관련 지표 ID와 스프레드 식도 함께 기억합니다. 세로축 값은 저장하지 않습니다.
- 사이드바의 날짜를 눌러 **시점 / 구간**과 날짜를 수정합니다. 새 글은 작성 순간 켜 둔 지표와 스프레드를 별도 조작 없이 자동 입력하며, 연결 목록은 제목 위 **인사이트 설정(···)** 에서 확인합니다. 필요할 때만 ‘관련 그래프 수정’을 열어 변경합니다. ‘현재 표시 그래프로 바꾸기’는 이후 켜 둔 그래프로 목록을 교체하는 선택 기능입니다. 연결이 없는 이전 글은 당시 지표를 알 수 없으므로 안내와 ‘현재 그래프 연결’ 버튼을 유지합니다.
- 설정에서 관련 지표의 표시 중/숨김 상태를 보여 줍니다. 연결 지표가 숨겨져 있으면 글 상단에도 복원 버튼을 표시합니다. **관련 그래프 보기**는 저장한 조합과 스프레드, 글의 기간을 불러옵니다. 체크박스를 바꾸거나 기간을 탐색해도 저장한 연결은 바뀌지 않습니다.
- 구간 글을 선택하면 **차트 아래 ‘이 구간의 변화’** 에 연결 지표의 첫 값 → 마지막 값, 변화량·변화율, 실제 관측일과 선택적 최고·최저를 표시합니다. 원래 값으로 계산하고 금리는 %p, 스프레드는 %p/bp를 씁니다. 양수가 아닌 시작값의 변화율은 계산하지 않습니다. 기간 안에 관측값이 2개 이상 필요하며 스프레드는 두 원자료 모두 기간 안에 있어야 합니다.
- **본문에 인용**은 현재 요약을 글에 고정합니다. 자동 요약은 최신 시계열을 사용하지만 인용한 숫자는 변경되지 않습니다. 연결이 없는 기존 글은 ‘현재 표시 지표 · 아직 연결 안 됨’으로 명시합니다.
- 상단 ‘인사이트 작성’은 현재 구간의 중앙 날짜로 글을 만듭니다. 왼쪽 날짜 도구는 차트를 클릭해서, 기간 도구는 시작~끝을 드래그해서 만듭니다. 날짜는 사이드바에서 수정할 수 있습니다. Esc는 기록 도구를 취소합니다.
- 기본 차트에는 배지를 표시합니다. 가까운 배지는 묶고 클릭하면 해당 시기의 글을 고를 수 있습니다. 글을 선택하면 오른쪽에 본문, 차트에 해당 날짜의 세로선 또는 기간 음영과 짧은 설명이 나타납니다.
- 다른 글을 선택하면 차트 표시도 전환합니다. 목록으로 돌아가면 상세 표시는 사라집니다. ‘이 기간 보기’는 기록 주변으로 차트를 이동합니다.
- 오른쪽은 제목·본문·날짜 검색을 지원합니다. 지표 선택이나 기간 탐색은 글을 변경하지 않습니다. 글은 공용이며, 표시 지표·보기 옵션·탐색 범위는 개인 설정입니다.
- 본문·차트 설명은 입력 중 기기 초안에 기록하고 잠시 멈추면 서버 저장을 시도합니다. 제목·날짜는 blur/Enter에서 확정합니다. 동시 편집 비교는 기존 포커스 범위와 협업 엔진을 사용합니다. 입력 칸을 벗어나면 저장 결과·충돌 상태가 반영됩니다.
- 잘못된 제목·날짜는 안내하고 해당 필드의 이전 값을 유지합니다. 긴 본문을 초기화하지 않습니다. 삭제는 확인 후 처리하며 기존 변경 이력에서 복원할 수 있습니다.

### 차트 탐색

- 커서 시간선과 만나는 선 중 위아래 18px 안의 선을 찾아 색 점·지표명·원래 값만 한 줄씩 표시합니다. 흰색 원도 모두 같은 시간선 위에 표시합니다. 여러 선이 가까우면 선택한 지표 순서대로 함께 표시합니다. 시간선은 유지하고 기존 상단 전체 지표 수치 나열은 안내로 대체합니다.
- 값은 커서 시점에 가장 가까운 실제 관측값입니다. 큰 흐름 모드는 그려진 선으로 위치를 판정하되 생략 전의 관측값을 사용합니다. 결측 구간을 연결하거나 값을 보간하지 않습니다. 툴팁은 페이지 배치와 분리된 고정 레이어에서 화면 안으로 배치하며, 목록이 길면 여러 열로 나눕니다. 스크롤바·높이 측정에 따른 흔들림 없이 마우스 이벤트를 차트로 통과시킵니다.
- 지표는 거시경제·주식시장·금리·통화·대외·연준 유동성의 분류별 체크박스로 켜고 끕니다. ‘표시 지표’를 누르면 차트 위 팝오버로 목록이 열립니다. 바깥 클릭이나 Esc로 닫습니다. 선택 요약은 상단에 유지합니다.
- 기준월=100은 개수 제한이 없고, 원래 값은 최대 2개입니다. 원래 값 모드에서 한도에 도달하면 미선택 항목만 비활성화하며, 기존 선택을 해제하면 다른 지표를 바로 켤 수 있습니다.

- 차트 안 드래그: 가로 이동. 휠: 커서 시점을 중심으로 확대·축소. Shift+휠: 가로 이동.
- 가로축 드래그: 기간 축척 조절. 세로축 드래그/휠: 값 축척 조절.
- 원래 값 모드에서는 좌우 세로축을 독립 조절합니다. 기준월=100은 공통 축입니다. ‘세로축 자동’으로 복귀할 수 있습니다.
- 지표 조합·표시 방식 변경 시 세로축은 자동 맞춤으로 초기화합니다. 직접 조절한 값 범위는 일반 기간 이동 중 유지합니다.
- 하단 슬라이더를 **월 / 연 / 전체** 버튼으로 교체했습니다. 월은 현재 중앙 시점 기준 24개월, 연은 20년 축척입니다. 데이터는 월 단위를 유지하며 연평균으로 집계하지 않습니다. 눈금은 달력 월/연 경계에 맞춥니다. 휠로 축척을 바꾸면 자유 축척으로 전환합니다.
- 하단 **날짜로 이동**을 열고 날짜 입력 후 이동/Enter를 누르면 현재 축척을 유지하면서 해당 시점을 중앙으로 옮기고 잠시 위치를 표시합니다. 자료 양 끝에서는 범위를 경계에 맞춥니다. 키보드 좌우 화살표는 이동, +/-는 확대·축소입니다.
- 큰 흐름·국면 배경·기준월=100 계산과 결측 처리 원칙은 기존과 같습니다. 새 보기에서는 국면 배경과 경제사 표시는 기본으로 꺼집니다.

### 스프레드

- 왼쪽 **스프레드 계산**에서 A와 B를 고르고 적용하면 같은 시간축의 하단 차트에 A−B를 표시합니다. A/B 교환과 제거를 지원합니다.
- 첫 버전은 연준 정책금리·미국 3개월 국채·10년 국채의 금리 차이를 지원합니다. 일본 금리는 아직 수록하지 않았습니다. 같은 지표끼리 계산하거나 단위가 다른 지표를 빼는 것은 허용하지 않습니다.
- 기준월=100 변환 전 원래 금리로 계산하고 0선을 표시합니다. 두 자료가 있는 공통 월만 사용하며 결측 구간은 연결하지 않습니다. 커서에는 A/B 원래 값과 각 관측일, 차이 %p/bp가 나타납니다.
- 스프레드는 메인 지표 체크박스와 독립적이며 한 식을 표시합니다. 선택한 기간·휠 확대·가로 이동을 두 차트가 공유합니다.

### 기존 카드·가져온 사건

- ‘사건 가져오기’ 및 배치 편집 UI를 **경제사 참고** 탭의 읽기 전용 기능으로 정리했습니다.
- 기존 경제사 카드 전체를 제목/본문으로 검색하고 펼쳐 읽습니다. 원문·노랑/파랑 메모·표를 표시하며 원본 카드로 이동할 수 있습니다.
- 인사이트를 선택하고 ‘경제사 참고’를 열면 날짜·구간에 겹치는 참고 카드로 자동 스크롤합니다. 여러 개면 인사이트 시작일에 가까운 카드, 겹치는 자료가 없으면 가장 가까운 시기를 선택합니다. 경제사 카드와 날짜가 있는 기존 사건을 함께 찾으며 목록은 날짜순입니다.
- 검색과 시기 안내는 상단에 유지하고 대상 카드를 강조합니다. 수동으로 스크롤하거나 검색하는 동안 자동으로 되돌리지 않으며 ‘이 시기로 이동’으로 다시 찾을 수 있습니다. 차트의 참고 사건을 직접 클릭하면 해당 선택을 우선합니다. 원문과 인사이트 저장값은 바뀌지 않습니다.
- 기존에 가져온 사건의 저장 데이터는 변경·이관·삭제하지 않습니다. 별도 참고 목록에서 읽으며 원본이 없어도 기존 제목·날짜를 보존합니다.
- ‘차트에 참고 사건 표시’를 켜면 카드와 날짜가 지정된 기존 사건을 하단 시간축에 함께 표시합니다. 묶음 클릭 시 해당 참고 자료를 사이드바에 표시합니다.
- 이 탭에서 참고 자료를 읽거나 그래프를 탐색하는 동작은 경제사 원본이나 기존 사건에 쓰기 요청을 보내지 않습니다.

### 저장/API

- 새 리소스: `note:<uuid>`, DB 키: `cap_settings.comparison_insight:<uuid>`. 별도 테이블이나 DDL은 필요하지 않습니다.
- 선택 필드 `context: { ids: string[], spread: {a,b} | null } | null`을 추가했습니다. 기존 문서에 필드를 강제하지 않습니다. 연결 지표는 개수 제한이 없으며 연결 설정은 하나의 필드로 충돌 검사하고, 본문·날짜와는 독립 병합합니다.
- 새 조회: `GET /api/capitalism/collab/insights`. 기존 resource/edit/history 경로가 note 리소스를 지원하고 state 응답에 notes 버전 목록을 추가합니다.
- 기존 `plot:` / `comparison_node:` 계약과 조회 API는 유지합니다. 이전 클라이언트가 새 인사이트를 기존 배치로 해석하지 않습니다.
- 개인 설정 `comparison-view-v2`는 v1의 지표·기준월·기간·단순화를 이어받되 경제사·국면 표시는 기본으로 끕니다.
- 프론트엔드와 API를 함께 배포해야 새 글 조회·저장이 작동합니다.

## 사용법

1. 기본 달러 접합지수·원/달러·엔/달러 또는 원하는 기존 경제사 지표를 선택합니다.
2. 기준월=100으로 개수 제한 없이, 원래 값/좌우 축으로 최대 2개를 비교합니다. 원래 값으로 전환할 때 앞의 2개만 남깁니다.
3. 날짜 입력이나 아래 탐색 막대의 양 끝으로 구간을 확대하고, 선택 영역을 밀어 이동합니다. 기준월은 구간 이동에 따라 바뀌지 않습니다.
4. **사건 가져오기**에서 카드를 펼쳐 내부 노드를 선택합니다. 여러 카드의 노드를 가져올 수 있습니다.
5. 가져온 사건 목록에서 노드를 선택하고 시작일·선택적 종료일을 직접 지정합니다. 날짜가 없으면 미배치 목록에 남습니다.
6. 날짜가 있는 노드는 그래프 위 사건 띠에 표시됩니다. 원본 카드별 행을 만들고 제목이 겹치면 하위 줄로 배치합니다.
7. 선택한 사건은 그래프에서 강조하고, **이 사건 구간 보기**로 주변을 확대합니다. 원문·메모·표를 확인하고 **원본 카드**로 이동할 수 있습니다.

## 큰 흐름 · 국면 · 시대적 사건

- **원본 / 큰 흐름** 토글은 선에 표시할 관측점만 줄입니다. 3·6·12·24개월 달력 구간마다 실제 최고·최저 관측값의 원래 날짜를 남기고 직선으로 연결합니다. 구간 내 작은 굴곡은 생략하므로 모든 국소 고저점을 보존하는 것은 아닙니다. 표시 구간의 양 끝과 각 결측 구간의 경계도 남깁니다.
- 두 모드의 기준월 정규화는 동일하게 `원래 관측값 / 기준월 원래 값 × 100`입니다. 세로축도 생략 전 전체 관측값으로 계산하여 전환 시 유지합니다. 툴팁은 생략한 월도 실제 값을 보여 줍니다. 결측은 연결하지 않으며, 시작 구간을 평균 계산 때문에 잘라내지 않습니다. 초기 이동평균 방식에서 고점이 낮아지고 늦어지던 문제를 이 방식으로 교체했습니다.
- **국면 배경**은 선택한 기준 지표의 대략적인 상승·하강 경향입니다. 12개월 이동평균을 6개월 전과 비교하고, 두 평균의 절댓값 중 큰 값의 1%보다 큰 변화가 있을 때 방향을 바꿉니다. 그 안의 작은 변화는 직전 방향을 유지하고 최초에는 방향 미정입니다. 충분한 자료가 없거나 결측 구간이면 배경도 비웁니다.
- 국면 계산은 표시 구간·기준월·선의 단순화 구간과 독립적입니다. 기준 지표가 선택 목록에서 빠지면 첫 지표로 전환합니다. 상승은 해당 지표의 수치 상승이며 호황·자금 유입·달러 강세 등을 일괄 판정하는 의미는 아닙니다. 평균을 사용하므로 실제 변곡보다 늦게 전환될 수 있습니다.
- **경제사 카드 표시**는 유효한 날짜가 있는 기존 카드의 제목을 같은 시간축에 표시합니다. 화면상 가까운 사건은 묶고 확대하면 나뉩니다. 클릭하면 해당 카드 목록·노드 본문·메모를 읽고 원본으로 이동할 수 있습니다. 원인을 자동 작성하거나 사건 날짜를 재해석하지 않습니다.
- 자동으로 표시한 경제사 카드와 직접 가져와 날짜를 지정한 노드 배치는 별도입니다. 경제사 카드를 숨겨도 직접 배치한 사건은 유지됩니다.

'원래 값' 모드는 지표마다 세로축이 따로라 두 선의 높낮이를 직접 비교하기 어렵습니다 — 한 선으로 보려면 **수출−수입 증가율 격차**(`trade_cycle` = 수출 증가율 − 수입 증가율, %p)를 켭니다. 0 위면 수출 사이클(수출이 더 빨리 늘어 수지 개선 방향), 0 아래면 수입 사이클입니다. '원래 값' 모드에서 0 을 지나는 계열은 그 계열 색의 점선 0 기준선이 함께 그려집니다. 그 이전 장기 흐름은 기존 분기 지표 '실질 순수출'(1947~)을 씁니다.

- 기준월에 모든 지표의 양수 값이 없으면 요청월 이후 첫 공통 양수 월을 명시하여 적용합니다. 공통 기준값이 없으면 변환 그래프를 표시하지 않고 기준·지표 변경 또는 원래 값 사용을 안내합니다.

## 2026-10-23: 인사이트의 돈·물건 변화 도표 (로컬 구현)

### 후속 디자인 피드백

- 돈은 노랑, 물건은 보라. 증가는 진한 채움, 감소는 같은 색의 옅은 채움과 테두리로 구분하며 0선 위/아래 및 증감 문구를 함께 사용합니다.

### 인사이트 간 양방향 전환

- 도표의 현재 높이는 사이드바에서 유지하고, 본문 편집기는 기존처럼 인사이트별로 분리합니다. 앞/뒤 화살표와 목차·차트 선택 모두 같은 전환을 사용합니다.
