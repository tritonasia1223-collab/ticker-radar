# 그래프 비교(베타)

## 2026-09-18 개편: 차트와 시간 기준 인사이트

현재 화면은 차트를 중심에 두고 왼쪽에 선택·이동 / 날짜 기록 / 기간 기록 도구, 오른쪽에 **인사이트 / 경제사 참고** 사이드바를 둡니다. 아래의 기존 사용법은 9월 14일 버전의 기록이며, 현재 동작은 이 절을 기준으로 합니다.

### 인사이트 작성과 열람

- **배지 하나 = 글 하나**입니다. 제목·시작일·선택적 종료일·자유 본문·선택적 차트 설명을 저장합니다. 위치는 시간 기준이며, 관련 지표 ID와 스프레드 식도 함께 기억합니다. 세로축 값은 저장하지 않습니다.
- 사이드바에서 **시점 / 구간**을 선택합니다. 새 글은 작성 순간 켜 둔 지표와 스프레드를 별도 조작 없이 자동 입력하며, 목록과 자동 입력 안내를 바로 보여 줍니다. 필요할 때만 접힌 ‘관련 그래프 수정’을 열어 변경합니다. ‘현재 표시 그래프로 바꾸기’는 이후 켜 둔 그래프로 목록을 교체하는 선택 기능입니다. 연결이 없는 이전 글은 당시 지표를 알 수 없으므로 안내와 ‘현재 그래프 연결’ 버튼을 유지합니다.
- 글을 열면 관련 지표의 표시 중/숨김 상태를 보여 줍니다. **관련 그래프 보기**는 저장한 조합과 스프레드, 글의 기간을 불러옵니다. 체크박스를 바꾸거나 기간을 탐색해도 저장한 연결은 바뀌지 않습니다.
- 구간 글의 본문 아래에 연결 지표의 첫 값 → 마지막 값, 변화량·변화율, 실제 관측일과 선택적 최고·최저를 표시합니다. 원래 값으로 계산하고 금리는 %p, 스프레드는 %p/bp를 씁니다. 양수가 아닌 시작값의 변화율은 계산하지 않습니다. 기간 안에 관측값이 2개 이상 필요하며 스프레드는 두 원자료 모두 기간 안에 있어야 합니다.
- **본문에 인용**은 현재 요약을 글에 고정합니다. 자동 요약은 최신 시계열을 사용하지만 인용한 숫자는 변경되지 않습니다. 연결이 없는 기존 글은 ‘현재 표시 지표 · 아직 연결 안 됨’으로 명시합니다.
- 상단 ‘인사이트 작성’은 현재 구간의 중앙 날짜로 글을 만듭니다. 왼쪽 날짜 도구는 차트를 클릭해서, 기간 도구는 시작~끝을 드래그해서 만듭니다. 날짜는 사이드바에서 수정할 수 있습니다. Esc는 기록 도구를 취소합니다.
- 기본 차트에는 배지를 표시합니다. 가까운 배지는 묶고 클릭하면 해당 시기의 글을 고를 수 있습니다. 글을 선택하면 오른쪽에 본문, 차트에 해당 날짜의 세로선 또는 기간 음영과 짧은 설명이 나타납니다.
- 다른 글을 선택하면 차트 표시도 전환합니다. 목록으로 돌아가면 상세 표시는 사라집니다. ‘이 기간 보기’는 기록 주변으로 차트를 이동합니다.
- 오른쪽은 제목·본문·날짜 검색을 지원합니다. 지표 선택이나 기간 탐색은 글을 변경하지 않습니다. 글은 공용이며, 표시 지표·보기 옵션·탐색 범위는 개인 설정입니다.
- 본문·차트 설명은 입력 중 기기 초안에 기록하고 잠시 멈추면 서버 저장을 시도합니다. 제목·날짜는 blur/Enter에서 확정합니다. 동시 편집 비교는 기존 포커스 범위와 협업 엔진을 사용합니다. 입력 칸을 벗어나면 저장 결과·충돌 상태가 반영됩니다.
- 잘못된 제목·날짜는 안내하고 해당 필드의 이전 값을 유지합니다. 긴 본문을 초기화하지 않습니다. 삭제는 확인 후 처리하며 기존 변경 이력에서 복원할 수 있습니다.

### 차트 탐색

- 지표는 거시경제·주식시장·금리·통화·대외·연준 유동성의 분류별 체크박스로 켜고 끕니다. 목록은 기본으로 펼쳐지고 ‘표시 지표’ 버튼으로 접을 수 있습니다. 선택 요약은 상단에 유지합니다.
- 기준월=100은 최대 4개, 원래 값은 최대 2개입니다. 한도에 도달하면 미선택 항목만 비활성화하며, 기존 선택을 해제하면 다른 지표를 바로 켤 수 있습니다.

- 차트 안 드래그: 가로 이동. 휠: 커서 시점을 중심으로 확대·축소. Shift+휠: 가로 이동.
- 가로축 드래그: 기간 축척 조절. 세로축 드래그/휠: 값 축척 조절.
- 원래 값 모드에서는 좌우 세로축을 독립 조절합니다. 기준월=100은 공통 축입니다. ‘세로축 자동’으로 복귀할 수 있습니다.
- 지표 조합·표시 방식 변경 시 세로축은 자동 맞춤으로 초기화합니다. 직접 조절한 값 범위는 일반 기간 이동 중 유지합니다.
- 하단 슬라이더를 **월 / 연 / 전체** 버튼으로 교체했습니다. 월은 현재 중앙 시점 기준 24개월, 연은 20년 축척입니다. 데이터는 월 단위를 유지하며 연평균으로 집계하지 않습니다. 눈금은 달력 월/연 경계에 맞춥니다. 휠로 축척을 바꾸면 자유 축척으로 전환합니다.
- 하단 **날짜 이동** 입력 후 이동/Enter를 누르면 현재 축척을 유지하면서 해당 시점을 중앙으로 옮기고 잠시 위치를 표시합니다. 자료 양 끝에서는 범위를 경계에 맞춥니다. 키보드 좌우 화살표는 이동, +/-는 확대·축소입니다.
- 큰 흐름·국면 배경·기준월=100 계산과 결측 처리 원칙은 기존과 같습니다. 새 보기에서는 국면 배경과 경제사 표시는 기본으로 꺼집니다.

### 스프레드

- 왼쪽 **스프레드 계산**에서 A와 B를 고르고 적용하면 같은 시간축의 하단 차트에 A−B를 표시합니다. A/B 교환과 제거를 지원합니다.
- 첫 버전은 연준 정책금리·미국 3개월 국채·10년 국채의 금리 차이를 지원합니다. 일본 금리는 아직 수록하지 않았습니다. 같은 지표끼리 계산하거나 단위가 다른 지표를 빼는 것은 허용하지 않습니다.
- 기준월=100 변환 전 원래 금리로 계산하고 0선을 표시합니다. 두 자료가 있는 공통 월만 사용하며 결측 구간은 연결하지 않습니다. 커서에는 A/B 원래 값과 각 관측일, 차이 %p/bp가 나타납니다.
- 스프레드는 메인 지표 체크박스와 독립적이며 한 식을 표시합니다. 선택한 기간·휠 확대·가로 이동을 두 차트가 공유합니다.

### 기존 카드·가져온 사건

- ‘사건 가져오기’ 및 배치 편집 UI를 **경제사 참고** 탭의 읽기 전용 기능으로 정리했습니다.
- 기존 경제사 카드 전체를 제목/본문으로 검색하고 펼쳐 읽습니다. 원문·노랑/파랑 메모·표를 표시하며 원본 카드로 이동할 수 있습니다.
- 인사이트를 선택하고 ‘경제사 참고’를 열면 날짜·구간에 겹치는 참고 카드로 자동 스크롤합니다. 여러 개면 인사이트 시작일에 가까운 카드, 겹치는 자료가 없으면 가장 가까운 시기를 선택합니다. 경제사 카드와 날짜가 있는 기존 사건을 함께 찾으며 목록은 날짜순입니다.
- 검색과 시기 안내는 상단에 유지하고 대상 카드를 강조합니다. 수동으로 스크롤하거나 검색하는 동안 자동으로 되돌리지 않으며 ‘이 시기로 이동’으로 다시 찾을 수 있습니다. 차트의 참고 사건을 직접 클릭하면 해당 선택을 우선합니다. 원문과 인사이트 저장값은 바뀌지 않습니다.
- 기존에 가져온 사건의 저장 데이터는 변경·이관·삭제하지 않습니다. 별도 참고 목록에서 읽으며 원본이 없어도 기존 제목·날짜를 보존합니다.
- ‘차트에 참고 사건 표시’를 켜면 카드와 날짜가 지정된 기존 사건을 하단 시간축에 함께 표시합니다. 묶음 클릭 시 해당 참고 자료를 사이드바에 표시합니다.
- 이 탭에서 참고 자료를 읽거나 그래프를 탐색하는 동작은 경제사 원본이나 기존 사건에 쓰기 요청을 보내지 않습니다.

### 저장/API

- 새 리소스: `note:<uuid>`, DB 키: `cap_settings.comparison_insight:<uuid>`. 별도 테이블이나 DDL은 필요하지 않습니다.
- 선택 필드 `context: { ids: string[], spread: {a,b} | null } | null`을 추가했습니다. 기존 문서에 필드를 강제하지 않습니다. 지표는 최대 4개이며 연결 설정은 하나의 필드로 충돌 검사하고, 본문·날짜와는 독립 병합합니다.
- 새 조회: `GET /api/capitalism/collab/insights`. 기존 resource/edit/history 경로가 note 리소스를 지원하고 state 응답에 notes 버전 목록을 추가합니다.
- 기존 `plot:` / `comparison_node:` 계약과 조회 API는 유지합니다. 이전 클라이언트가 새 인사이트를 기존 배치로 해석하지 않습니다.
- 개인 설정 `comparison-view-v2`는 v1의 지표·기준월·기간·단순화를 이어받되 경제사·국면 표시는 기본으로 끕니다.
- 프론트엔드와 API를 함께 배포해야 새 글 조회·저장이 작동합니다.

- 1280/1920px 데스크톱 및 390px 모바일에서 문서 가로 넘침이 없음을 확인했습니다. 좁은 화면에서는 사이드바가 차트 아래로 이동하고 차트 자체는 가로 탐색할 수 있습니다.
- 브라우저 예시 인사이트는 합성 자료이며 운영 연구 데이터에 생성하지 않았습니다.

## 이전 버전 기록 (2026-09-14~15)

경로 `/#/graph-compare`. 사이드바에서 **자본주의 경제사 바로 아래**에 있는 독립 페이지입니다.

## 사용법

1. 기본 달러 접합지수·원/달러·엔/달러 또는 원하는 기존 경제사 지표를 선택합니다.
2. 기준월=100으로 최대 4개, 원래 값/좌우 축으로 최대 2개를 비교합니다. 원래 값으로 전환할 때 앞의 2개만 남깁니다.
3. 날짜 입력이나 아래 탐색 막대의 양 끝으로 구간을 확대하고, 선택 영역을 밀어 이동합니다. 기준월은 구간 이동에 따라 바뀌지 않습니다.
4. **사건 가져오기**에서 카드를 펼쳐 내부 노드를 선택합니다. 여러 카드의 노드를 가져올 수 있습니다.
5. 가져온 사건 목록에서 노드를 선택하고 시작일·선택적 종료일을 직접 지정합니다. 날짜가 없으면 미배치 목록에 남습니다.
6. 날짜가 있는 노드는 그래프 위 사건 띠에 표시됩니다. 원본 카드별 행을 만들고 제목이 겹치면 하위 줄로 배치합니다.
7. 선택한 사건은 그래프에서 강조하고, **이 사건 구간 보기**로 주변을 확대합니다. 원문·메모·표를 확인하고 **원본 카드**로 이동할 수 있습니다.

## 큰 흐름 · 국면 · 시대적 사건

- **원본 / 큰 흐름** 토글은 선에 표시할 관측점만 줄입니다. 3·6·12·24개월 달력 구간마다 실제 최고·최저 관측값의 원래 날짜를 남기고 직선으로 연결합니다. 구간 내 작은 굴곡은 생략하므로 모든 국소 고저점을 보존하는 것은 아닙니다. 표시 구간의 양 끝과 각 결측 구간의 경계도 남깁니다.
- 두 모드의 기준월 정규화는 동일하게 `원래 관측값 / 기준월 원래 값 × 100`입니다. 세로축도 생략 전 전체 관측값으로 계산하여 전환 시 유지합니다. 툴팁은 생략한 월도 실제 값을 보여 줍니다. 결측은 연결하지 않으며, 시작 구간을 평균 계산 때문에 잘라내지 않습니다. 초기 이동평균 방식에서 고점이 낮아지고 늦어지던 문제를 이 방식으로 교체했습니다.
- **국면 배경**은 선택한 기준 지표의 대략적인 상승·하강 경향입니다. 12개월 이동평균을 6개월 전과 비교하고, 두 평균의 절댓값 중 큰 값의 1%보다 큰 변화가 있을 때 방향을 바꿉니다. 그 안의 작은 변화는 직전 방향을 유지하고 최초에는 방향 미정입니다. 충분한 자료가 없거나 결측 구간이면 배경도 비웁니다.
- 국면 계산은 표시 구간·기준월·선의 단순화 구간과 독립적입니다. 기준 지표가 선택 목록에서 빠지면 첫 지표로 전환합니다. 상승은 해당 지표의 수치 상승이며 호황·자금 유입·달러 강세 등을 일괄 판정하는 의미는 아닙니다. 평균을 사용하므로 실제 변곡보다 늦게 전환될 수 있습니다.
- **경제사 카드 표시**는 유효한 날짜가 있는 기존 카드의 제목을 같은 시간축에 표시합니다. 화면상 가까운 사건은 묶고 확대하면 나뉩니다. 클릭하면 해당 카드 목록·노드 본문·메모를 읽고 원본으로 이동할 수 있습니다. 원인을 자동 작성하거나 사건 날짜를 재해석하지 않습니다.
- 자동으로 표시한 경제사 카드와 직접 가져와 날짜를 지정한 노드 배치는 별도입니다. 경제사 카드를 숨겨도 직접 배치한 사건은 유지됩니다.

## 데이터와 해석

- 원/달러: [FRED EXKOUS](https://fred.stlouisfed.org/series/EXKOUS), 원/1달러, 월평균, 1981-04~2026-08.
- 엔/달러: [FRED EXJPUS](https://fred.stlouisfed.org/series/EXJPUS), 엔/1달러, 월평균, 1971-01~2026-08.
- 위 두 환율의 상승은 달러 강세/상대 통화 약세입니다. 미완료 월은 수록하지 않습니다.
- 기존 달러 계열은 주요통화 명목지수와 BIS 광의 명목지수의 접합 계열입니다. 공식 DXY로 표시하지 않습니다.
- 원래 발표된 월간·분기 값은 유지하고, 일·주간 자료는 각 월 마지막 관측값을 사용합니다. 원래 관측일은 툴팁에 표시합니다. 결측을 채우거나 결측 구간을 선으로 연결하지 않습니다.
- 기준월에 모든 지표의 양수 값이 없으면 요청월 이후 첫 공통 양수 월을 명시하여 적용합니다. 공통 기준값이 없으면 변환 그래프를 표시하지 않고 기준·지표 변경 또는 원래 값 사용을 안내합니다.
- 기준월=100은 선택한 월 대비 상대 변화입니다. 지표의 경제적 의미가 같아진다는 뜻은 아닙니다. 실질 순수출은 2017년 연쇄달러·계절조정 연율, 인플레이션은 CPI 수준이 아닌 전년 대비 변화율입니다.
- 월간 갱신은 기존 `script/fetch-capitalism-series.ts`/GitHub Actions에 연결됩니다. 계열 로더의 공용 청크 분리도 배포 검증기가 추적합니다.

## 원본과 저장

- 원본을 복사하거나 분해하여 수정하지 않습니다. `flowSlug + nodeKey`를 참조하고 연표용 제목·날짜만 별도로 저장합니다.
- 원문 수정은 반영됩니다. 원문이 삭제되어도 배치를 보존하고 **원본 없음** 상태를 표시합니다. 배치 제거는 원본을 삭제하지 않습니다.
- 공용 보드 1개이며 노드마다 `plot:<uuid>` 협업 리소스를 사용합니다. 기존 `cap_settings`의 `comparison_node:<uuid>` 키에 저장하므로 추가 DDL은 필요하지 않습니다.
- 변경은 기존 협업 엔진/변경 이력으로 처리합니다. 다른 배치는 독립 저장, 같은 배치의 다른 필드는 병합, 같은 필드는 충돌 선택 대상입니다. 삭제는 버전 있는 null 문서를 남겨 다른 창에 전달합니다.
- 제목·날짜는 blur에서 확정합니다. 날짜 입력의 중복 포커스 이벤트가 편집 잠금을 누적하지 않도록 공통 포커스 훅을 보완했습니다.
- 지표 선택·기준월·확대 범위·단순화·국면 기준·경제사 표시 여부는 브라우저의 개인 보기 설정입니다. 탐색은 서버에 저장하지 않습니다. 발표 모드에서도 탐색할 수 있으며 배치 수정은 숨깁니다.
- 새 API: `GET /api/capitalism/collab/comparison`. 기존 `resource`, `edit`, `state`가 `plot:`을 지원합니다. 기존 경제사 서버 쓰기는 유지합니다.

## 검증 (2026-09-14)

- 계산/날짜/결측/서버 변경 경로 테스트와 기존 회귀 테스트.
- 임시 PostgreSQL 스키마에서 실제 트랜잭션: 배치 생성, 독립 필드 동시 병합, 잘못된 기간 롤백, 삭제 버전 및 원본·메타 보존. 생성한 테스트 스키마만 제거했습니다.

- 편집/발표 전환 및 1280·1366·1920px 창에서 탐색. 실제 외부 모니터 연결은 별도 사용자 환경 확인 대상입니다.
