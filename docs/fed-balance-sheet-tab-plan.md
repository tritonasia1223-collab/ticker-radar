## 1. 목표와 범위

Fed 대차대조표(H.4.1)의 과거~현재 변동을 시각화하는 신규 탭.

- **범위**: 미국 유동성 전용 (BOJ/ECB 확장 없음 — 스키마도 단순하게 유지)
- **갱신 주기**: 매주 목요일 (H.4.1 발표 후). 일간 시리즈 2개(RRP, TGA)는 평일 일간 갱신
- **디자인 방향**: 정적이고 밀도 높은 대시보드. 장식적 모션 배제. 허용되는 트랜지션은 스크러버 조작 시 세그먼트 높이 변화(0.3~0.4s ease)와 숫자 트윈 정도
- **핵심 컴포넌트**: T-계정(시간 스크러버) + 주간 준비금 변화 워터폴

## 2. 데이터 소스 — FRED API

API 키는 환경변수 `FRED_API_KEY` (무료 발급, rate limit 120 req/min — 이 규모에서 무관).
엔드포인트: `https://api.stlouisfed.org/fred/series/observations?series_id={ID}&api_key={KEY}&file_type=json`

### 2.1 주간 시리즈 (H.4.1 계열, 수요일 기준값, 목요일 발표)

**자산 (차변)**

| series_id | 항목 | 비고 |
|---|---|---|
| `WALCL` | 총자산 | 헤드라인. 2002-12~ |
| `TREAST` | 국채 보유 | SOMA |
| `WSHOMCB` | MBS 보유 | SOMA |
| `WSHOFADSL` | 연방기관채 | SOMA. 잔존 미미하나 항등식 정합 위해 수집 |
| `WLCFLPCL` | 할인창구 (primary credit) | 위기 시그널 |
| `H41RESPPALDKNWW` | BTFP | 2023-03~2025-03. 현재 0이지만 히스토리 필수 |
| `WORAL` | 레포 | |
| `SWPT` | 중앙은행 통화스왑 | 위기 시그널 |

**부채 (대변)**

| series_id | 항목 | 비고 |
|---|---|---|
| `WRESBAL` | 지급준비금 | 잔차 크로스체크 대상 |
| `WLRRAL` | 역레포 (주간, H.4.1) | 일간 RRPONTSYD와 별개 시리즈 |
| `WDTGAL` | TGA (주간) | |
| `WCURCIR` | 화폐발행 | |

### 2.2 일간 시리즈

| series_id | 항목 | 용도 |
|---|---|---|
| `RRPONTSYD` | 역레포 (일간) | 순유동성 일간 추적 |
| `WTREGEN` | TGA (일간) | 순유동성 일간 추적 |
| `SP500` | S&P 500 | 순유동성 차트 오버레이 (Ticker Radar에 기존 가격 소스가 있으면 그쪽 우선) |

### 2.3 단위 정규화 — ⚠️ 최우선 주의사항

FRED 시리즈마다 단위가 다르다. **ingestion 시점에 전부 million USD로 통일**해서 저장한다.

- H.4.1 주간 시리즈(WALCL 등): millions → 그대로
- `RRPONTSYD`: **billions** → ×1,000
- 각 시리즈의 실제 단위는 `fred/series` 메타 엔드포인트의 `units` 필드로 **코드에서 확인 후 변환** (하드코딩 금지 — 시리즈별 units 응답을 파싱해 분기)

## 3. Supabase 스키마

```sql
create table fed_balance_sheet (
  series_id  text not null,
  obs_date   date not null,
  value_musd numeric,            -- million USD로 통일된 값
  primary key (series_id, obs_date)
);

create index idx_fbs_date on fed_balance_sheet (obs_date);
```

- 쓰기는 전부 `upsert ... on conflict (series_id, obs_date) do update` — cron 재실행 멱등성 확보 (인사이더 대시보드와 동일 패턴)
- 파생값(순유동성, 잔차 기타 항목)은 **저장하지 않고 프론트/API 레이어에서 계산** — 정의 변경 시 백필 불필요

## 4. 파생 계산 (프론트 또는 API 레이어)

```
SOMA        = TREAST + WSHOMCB + WSHOFADSL
대출·스왑    = WLCFLPCL + BTFP + WORAL + SWPT
기타자산(잔차) = WALCL − SOMA − 대출·스왑

부채4대     = WRESBAL + WLRRAL + WDTGAL + WCURCIR
기타부채·자본(잔차) = WALCL − 부채4대

순유동성(주간) = WALCL − WDTGAL − WLRRAL
순유동성(일간) = 최근 WALCL(forward-fill) − WTREGEN − RRPONTSYD
```

**워터폴 분해 (주간, w vs w−1):**

```
Δ준비금 = Δ자산(WALCL) − ΔTGA(WDTGAL) − Δ역레포(WLRRAL) − Δ현금통화(WCURCIR) − Δ기타부채·자본(잔차)
```

좌변(WRESBAL의 실제 주간 변화)과 우변(분해 합)이 일치해야 한다 → 테스트 F3.

**forward-fill 규칙**: 일간 순유동성 계산 시 WALCL은 직전 수요일 값을 유지. 주간 워터폴에 일간 시리즈를 섞지 않는다 — 워터폴은 전부 H.4.1 주간 시리즈(수요일 기준)만 사용해 날짜 정렬 문제를 원천 차단.

## 5. 파이프라인 — GitHub Actions

### 5.1 백필 (1회 수동 실행)

- 스크립트: `scripts/fed-backfill.mjs`
- 시리즈당 API 1회 호출로 전 기간 수신 → 단위 변환 → 일괄 upsert
- 수집 시작일: 각 시리즈의 최초 관측일부터 전부 (2002~). UI 기본 표시 범위는 2007-01~

### 5.2 주간 cron

- 스케줄: `30 22 * * 4` (UTC) — 목요일 22:30 UTC. H.4.1 발표(목 16:30 ET)는 EDT 기준 20:30 UTC, EST 기준 21:30 UTC이므로 연중 안전
- 대상: 2.1의 주간 시리즈 12개, 각각 최근 4주 재요청(수정치 반영) 후 upsert

### 5.3 일간 cron

- 스케줄: `0 23 * * 1-5` (UTC)
- 대상: RRPONTSYD, WTREGEN, SP500 — 최근 7일 재요청 후 upsert

## 6. Falsification Tests — 구현 전 정의, 통과가 완료 조건

`tests/fed-balance-sheet.test.mjs`

**F1. 단위 정합성 (앵커 검증)**
고정 기준일 2~3개(예: 2022-04-13, 2024-06-26)의 WALCL 저장값이 Fed 공식 H.4.1 수치와 일치. 기대값은 테스트에 상수로 박아둔다.
*실패 의미: 단위 변환 또는 파싱 오류.*

**F2. 복식부기 항등식**
모든 주간 관측일에 대해 `|기타부채·자본(잔차)| < WALCL × 10%` 그리고 잔차 ≥ 0에 가까운 합리 범위(음수로 크게 벗어나면 실패).
*실패 의미: 부채 시리즈 누락/단위 불일치/날짜 정렬 오류.*

**F3. 준비금 이중 검증**
잔차로 계산한 준비금(`WALCL − 타부채 − 자본잔차 상수 가정 없이`, 실제로는 워터폴 항등식)과 `WRESBAL` 실측의 주간 변화가 오차 $5B 이내로 일치하는 주가 전체의 95% 이상.
*실패 의미: 어느 한 시리즈의 단위·날짜가 틀어짐. 두 항등식(F2, F3)이 독립 크로스체크.*

**F4. 네거티브 컨트롤**
- 주말·연방 공휴일 날짜에 일간 시리즈(RRPONTSYD) 레코드가 **존재하지 않아야** 통과 — forward-fill이 가짜 관측치를 생성하지 않는지 확인
- BTFP의 2022년 이전 날짜에 레코드가 없어야 통과 (시리즈 시작 전 데이터 조작 없음)

**F5. 순유동성 크로스체크**
알려진 기준일(2022-12-28 부근)의 주간 순유동성이 시장 통용치 ~$6.1T 대비 ±3% 이내.

**회귀 기준**: F1~F5 전부 통과가 배포 조건. 네거티브 컨트롤(F4)이 결정적 회귀 증거.

## 7. UI 컴포넌트 명세

탭 라우트: `/fed` (기존 congress-tracker 탭과 동일한 라우팅/레이아웃 패턴 따름)

### 7.1 헤드라인 카드 (4개)

총자산 / 지급준비금 / 순유동성 / 주간 변화(WoW). 각 카드에 값 + 전주 대비 증감(색상: 증가/감소). QT 시작(2022-06) 대비 누적 축소액을 총자산 카드 서브텍스트로.

### 7.2 T-계정 (메인, 시간 스크러버 포함)

- 좌: 자산(차변) — SOMA / 대출·스왑 / 기타 3대분류 스택. hover 시 세부 항목(국채·MBS·기관채, 할인창구·BTFP·레포·스왑) 툴팁
- 우: 부채·자본(대변) — 준비금 / 역레포 / TGA / 현금통화 / 기타 스택
- 중앙 세로 구분선, 회계 장부 형태 유지
- **스케일 토글**: 절대값 모드(기본, 기둥 높이 = 총자산 비례, 최대값 기준 정규화) / 100% 구성비 모드
- **시간 스크러버**: 주간 전체 관측일에 매핑. 스크러버 트랙 아래에 WALCL 미니 면적 차트를 컨텍스트로 깔고, 국면 주석 마커 표시: QE1(2008-11), QE2(2010-11), QE3(2012-09), 테이퍼 탠트럼(2013-05), QT1(2017-10), 레포 위기(2019-09), 무제한 QE(2020-03), QT2(2022-06), SVB/BTFP(2023-03)
- 색상: 자산 = teal 계열 3단, 부채 = purple 계열 + 현금통화·기타는 gray. 세그먼트 높이 변화 트랜지션 0.3s ease만 허용
- 작은 세그먼트(높이 < 24px)는 라벨 숨기고 hover 툴팁으로

### 7.3 주간 준비금 변화 워터폴

- 구조: 지난주 준비금(앵커 바) → Δ자산 → ΔTGA → Δ역레포 → Δ현금통화·기타 → 이번주 준비금(앵커 바)
- 부호 반전 주의: TGA·역레포·현금의 **증가**는 준비금 **감소** 요인 (음수 바, red 계열). 감소는 유입(green 계열). Δ자산은 부호 그대로
- 기본: 최신 주. T-계정 스크러버와 주 선택 동기화
- 하단 요약 카드: 이번주 준비금 / 주간 변화 / 최대 요인(절대값 최대 항목 자동 표기)

### 7.4 대출 프로그램 차트 (위기 시그널)

- 자체 스케일 (T-계정에서는 실낱이라 안 보이는 항목들): 할인창구 + BTFP + 통화스왑 + 레포, 시계열 면적/선 차트
- 위기 밴드 주석: 2008 GFC, 2020-03, 2023-03 SVB
- 이 차트의 존재 이유를 캡션 한 줄로: "Fed 대출이 튀면 어딘가에서 불이 났다"

### 7.5 순유동성 차트

- WALCL − TGA − RRP, 일간 해상도 (WALCL forward-fill)
- S&P 500 오버레이 토글 (우측 보조축)
- 범위 선택: 1Y / 3Y / QT2 이후 / 전체
