# 경제사 그래프 비교 — 최소 기능 구현 계획

작성: 2026-09-14
상태: 최소 기능 구현 완료. 2026-09-15 `그래프 비교(베타)`로 배포 준비. 현재 사용법·검증은 [GRAPH-COMPARE.md](GRAPH-COMPARE.md).

## 목적과 범위

사용자가 작성한 경제사 카드에서 시간 전개가 중요한 노드를 직접 골라 가로 시간축에 재구성하고, 같은 시간축의 여러 거시 지표를 겹쳐 관찰한다. 자료 수집·해석 작성·사건 선정은 사용자가 한다. AI 해석이나 시나리오 생성은 이번 기능에 포함하지 않는다.

사용자 후속 지정에 따라 사이드바의 자본주의 경제사 바로 아래에 독립 `그래프 비교` 메뉴를 추가한다. 페이지 전체 폭을 사용한다. 기존 타임라인·인사이트 보기와 원본 카드 편집 동작은 유지한다. 별도 사이트를 만들지 않는다.

## 첫 화면

위에서 아래 순서:

1. 지표 선택 / 표시 방식 / 기간 / 사건 가져오기
2. 사건 진행 띠: 원본 카드별 행에 선택한 노드의 제목과 점 또는 기간 막대 표시
3. 큰 겹침 그래프: 사건 진행 띠와 동일한 날짜 범위·가로 좌표 사용
4. 전체 기간 탐색 막대: 양 끝을 조절해 확대하고 선택 영역을 밀어 이동

노드를 선택하면 상세 패널에 원문·메모·표를 보여주고 그래프의 해당 날짜 또는 기간을 강조한다. 상세 패널은 필요할 때만 열린다. 사건 띠에 원문 전체를 상시 펼치지 않는다.

## 최소 기능

### 1. 지표 겹치기

- 기존 경제사 지표를 재사용하고 원/달러·엔/달러 환율을 초기 추가 대상으로 삼는다. 실제 수록 범위와 공식 출처를 확인한 뒤 추가한다.
- 한 번에 최대 4개 선을 선택하고 범례에서 표시 여부를 변경한다.
- 기본 비교 모드는 `기준일=100`. 기준일은 명시하고 구간 확대만으로 자동 변경하지 않는다.
- `원래 값`은 최대 2개 지표까지 좌우 축으로 비교한다. 축마다 지표명과 단위를 표시한다.
- 공통 세로 커서에 날짜, 원래 값, 변환 값을 표시한다. 환율의 단위와 상승 방향을 명시한다.
- 기준일의 공통 관측값이 없으면 가능한 공통 기준 시점을 안내한다. 0 또는 음수 기준값 등 지수화가 부적절한 조합은 변환하지 않고 원래 값 사용을 안내한다.
- 결측 구간을 임의로 채우거나 선으로 연결하지 않는다. 서로 다른 관측 주기는 출처 정보와 툴팁에서 구분한다.
- 현재 `dollar`는 서로 다른 지수를 접합한 계열이다. 새 화면에서 이를 공식 DXY 원본처럼 표시하지 않는다. 기존 계열의 구성·출처를 밝히고 개별 공식 계열 추가 여부를 확인한다.
- 100년 전체에 모든 지표가 있다고 가정하지 않는다. 지표별 실제 수록 구간을 표시한다.

### 2. 구간 탐색

- 시작일·종료일 직접 입력 및 전체 기간 탐색 막대의 범위 조절.
- 선택 범위 이동과 전체 범위로 돌아가기.
- 사건 띠와 그래프가 같은 시간축을 사용한다.
- 확대·커서 이동은 개인의 화면 조작이며 공용 보드 저장을 발생시키지 않는다.

### 3. 원본 노드 가져오기

- `사건 가져오기`에서 카드 제목·노드 본문 검색 → 카드 내부 노드 복수 선택.
- 여러 카드에서 선택한 노드를 한 보드에 표시한다.
- 각 배치에 짧은 표시 제목, 시작일, 선택적 종료일을 지정한다.
- 카드 날짜는 입력 참고값으로 제공한다. 이를 실제 노드 발생일로 자동 확정하지 않는다.
- 날짜를 아직 지정하지 않은 노드는 미배치 목록에 보관하고 시간축에 임의 배치하지 않는다.
- 원본 카드별로 행을 나누고 같은 행의 제목이 겹치면 하위 줄로 정리한다. 복잡한 자유 배치와 연결선 편집은 다음 단계로 미룬다.
- 배치 삭제는 비교 보드에서만 제거한다. 원본 노드를 삭제하지 않는다.

### 4. 원문 연결

- 배치는 원본 카드의 slug와 안정적인 node key를 참조한다. 원문을 새 카드로 복사하지 않는다.
- 원문 수정은 비교 화면에서도 반영한다. 배치용 짧은 제목과 날짜는 별도로 유지한다.
- 클릭하면 기존 리치텍스트·메모·표를 읽기 전용으로 표시한다. 원본 카드로 이동해 수정할 수 있다.
- 원본 노드가 삭제되면 배치는 보존하고 `원본 없음` 상태를 표시한다. 사용자가 제거 여부를 결정한다.

### 5. 저장과 공동 사용

- 첫 버전은 두 사람이 함께 사용하는 비교 보드 1개로 시작한다.
- 공용 데이터: 노드 참조, 표시 제목, 날짜·기간, 표시 순서.
- 개인 화면 상태: 선택 지표, 기준일, 화면 범위, 커서. 공용 편집과 분리한다.
- 공용 배치는 서버에 저장한다. 기존 협업 엔진의 이전 값 비교·충돌 감지·기기 초안·재시도 방식을 활용한다.
- 기존 서버는 `flow:`와 `meta:` 리소스만 허용하므로 보드용 리소스·검증·읽기/쓰기·변경 수신 경로를 명시적으로 확장한다. 기존 메타 카드에 보드 데이터를 섞어 넣지 않는다.
- 배치 ID별 변경 경로로 저장해 다른 배치의 동시 편집은 병합하고 같은 필드 충돌은 감지한다. 전체 배열 덮어쓰기를 피한다.
- 제목·날짜 입력은 blur 또는 확정 시 저장하고 입력 도중 매 타자 서버 저장을 하지 않는다. 편집자 지정 절차를 추가하지 않는다.

## 구현 순서

1. **비교 화면 골격과 데이터 정의**: 독립 컴포넌트로 보기 추가, 기존 시계열 재사용, 환율 출처·단위·수록 범위 검증 및 갱신 경로 추가.
2. **겹침 그래프와 구간 탐색**: 원래 값/기준일=100, 공통 커서, 범위 조절. 이 단계에서 그래프만으로 먼저 사용 가능하게 한다.
3. **노드 선택과 사건 띠**: 카드 검색, 선택, 날짜 지정, 같은 시간축 배치, 원문 상세와 이동.
4. **서버 저장과 공동 편집 연결**: 보드 리소스와 항목별 저장, 원본 삭제 상태, 재접속 복원.
5. **검증 및 사용성 확인**: 실제 데이터로 편집·발표 모드와 화면 배율 조건을 점검하고 첫 버전을 마무리한다.

각 단계는 하나의 최소 버전을 완성하기 위한 내부 작업 순서다. 중간 단계의 로컬 전용 상태를 완성된 공용 기능으로 취급하지 않는다.

## 검증 기준

- 선택한 두 지표를 겹치고 범위를 바꿔도 같은 날짜에 사건과 그래프가 정확히 정렬된다.
- 기준일=100 계산, 단위·환율 방향, 결측 및 관측 주기 처리를 검증한다.
- 서로 다른 카드에서 노드를 가져와 날짜를 지정하고, 새로고침 및 다른 창에서 배치를 확인한다.
- 원문 수정·삭제와 배치 삭제를 구분하고 기존 카드 내용을 보존한다.
- 다른 배치 동시 편집은 병합하고 같은 배치의 같은 필드 충돌은 조용히 덮어쓰지 않는다.
- 저장 실패 시 배치 초안을 보존하고 재시도할 수 있다.
- 구간을 반복 이동해도 전체 원본 카드 에디터를 재렌더하지 않는다. 위치 측정은 필요할 때 프레임당 한 번만 수행한다.
- 편집/발표 모드, 좁고 넓은 화면, 배율 변화에서 반복 탐색을 검사한다. 기존 경제사의 blur 저장과 타임라인 이동도 회귀 확인한다.
- 관련 계산·공동 편집 테스트, 타입 검사, 빌드, 실제 브라우저 확인을 수행한다.

## 이후 개선 후보

- 여러 비교 보드와 지표 조합 저장.
- 노드 날짜 드래그 조절, 원본 카드와 무관한 사용자 지정 사건 묶음, 단계 사이 연결선.
- 같은 그래프의 다른 시대를 나란히 비교, 겹치기/분할 표시 전환.
- 이미지 내보내기, 발표용 배치 다듬기, 메모·구간 주석.

이번 계획에는 AI 자동 해석, 자동 사건 선정·날짜 추론, 사내 에이전트 구축, 전체 홈페이지 재배치를 포함하지 않는다.
