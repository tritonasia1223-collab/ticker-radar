운영 `/api/fed/overview`에서 확인한 최신 관측일:

- 주간 연준 데이터: **2026-09-02**.
- 월간 재무부 데이터: **2026-07-31**.
- 일간 응답의 마지막 날짜: **2026-08-31**. 일간 수집 함수는 있으나 현재 정기 워크플로는 `weekly`와 `mspd`만 실행하므로 일간 응답 전체가 정기 갱신된다는 뜻은 아닙니다.

화면의 준비금 변화 분해·국채 순발행·보유비중 등은 수집한 원자료를 계산한 결과입니다. 별도의 수집 일정은 없습니다. Fed 화면은 진입 시 조회하고, 열린 창에서 주기적으로 재조회하지는 않습니다.

## 2. 월간 예약으로 조사·검증·배포하는 정적 데이터

### 자본주의 경제사 차트 — 19개 시계열

`npm run cap:series -- --repair-last-month` → `client/src/data/capitalism-series.json` 갱신 → 검토·커밋·배포 순서입니다. 매월 3일 09:00 Codex 예약에서 실행하며 GitHub Actions 워크플로는 별도로 추가하지 않았습니다. 미국 유동성 DB 수집과 별도이므로 같은 연준 지표라도 두 화면의 마지막 관측일이 다를 수 있습니다.

| 구분 | 데이터 | 저장 파일의 마지막 관측일 |
|---|---|---|
| 금리 | 3개월 국채, 10년 국채, 연준 정책금리 | 모두 2026-08-01 |
| 거시 | 실업률, CPI 전년 대비 | 각각 2026-08-01, 2026-07-01 |

원천은 대부분 FRED이며 금은 `datasets/gold-prices`의 월간 CSV입니다. 월간·분기 관측일은 해당 기간의 대표 날짜이므로 마지막 날짜만 보고 수집 장애라고 단정할 수 없습니다. 스크립트는 기존 과거 값을 보존하고 신규 날짜를 덧붙입니다. 따라서 과거 수정치를 모두 자동 반영하는 방식도 아닙니다. 정의: [fetch-capitalism-series.ts](../script/fetch-capitalism-series.ts).

## 3. 수동 수집·생성 기능

| 데이터 | 실행 방법 | 현재 자동 일정 |
|---|---|---|
| X·Threads 게시글과 종목 언급 | 사이트 종목 갱신 버튼 또는 GitHub `collect` 수동 실행. `npm run collect`, `collect:threads` | 없음. `collect.yml`은 workflow_dispatch만 설정. 최근 기록은 2026-06-30 09:11 시작 후 취소 |
| 국내 관심종목 등록 순위 | `npm run collect:interest`, 한국투자증권 KIS API | 저장소 내 자동 일정 없음 |
| 종목별 ‘왜 뜨나’ 뉴스 요약 | `npm run reports` | 저장소 내 자동 일정 없음 |

SNS 최근 실행: [collect 기록](https://github.com/tritonasia1223-collab/ticker-radar/actions/runs/28411201978). 수동 갱신 기능의 실동작을 확인하려고 유료 수집을 새로 실행하지는 않았습니다.

## 4. 수집 주기와 혼동하기 쉬운 것

- 경제사 협업: **5초**마다 다른 창의 저장 버전을 확인합니다. 외부 경제지표를 수집하는 주기가 아닙니다.
- 접속 상태: **15초** 갱신, 마지막 신호로부터 **45초** 만료입니다.
- `npm run cap:watch`: 직접 실행해 둔 동안 기본 **120초** 간격으로 로컬 백업합니다. 항상 실행되는 서버 작업은 아닙니다.
- 보류된 CLO API: 요청이 들어왔을 때 외부 자료를 조회하고 보유종목은 **30분**, 거시 스프레드는 **6시간** 메모리 캐시합니다. 정기 백그라운드 수집은 아닙니다.
- Vercel 설정에는 별도 cron이 없습니다. DB 자동 수집 일정은 `.github/workflows/`, 경제사·세계 현황판 월간 일정은 Codex 예약 `fiscus`에서 관리합니다.

현재 메인 기능의 운영 형태는 **미국 유동성은 GitHub Actions로 DB 갱신 / 경제사·세계 현황판은 월간 Codex 예약으로 수집·조사·검증·배포**입니다.
