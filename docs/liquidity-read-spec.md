## 3. 공통 규칙

### 3.1 어휘

| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| **방출** / 시중에 풀었다 (유동성을 늘리는 쪽) | 꺼내 썼다, 헐었다, 지출 |
| **흡수** / 시중에서 빠졌다 (유동성을 줄이는 쪽) | 줄였다(목적어 없이), 축소 |
| **TGA** (첫 등장 시에만 "재무부가 연준에 둔 계좌") | 통장, 재무부 통장, 재무부 계좌(단독) |
| 순유동성 (첫 등장 시 "시장에 도는 돈") | |
| 역레포 | RRP(본문에서는 한글) |

### 3.2 부호와 색 — 단 하나의 규칙

- **초록 `#1F7A4D` = 방출(순유동성 증가에 기여)**, **빨강 `#B3402E` = 흡수(감소에 기여)**.
- 본문에 나오는 모든 Δ는 **"순유동성에 준 영향" 부호**로 표시한다. TGA 잔고가 1,157억 줄었으면 본문에는 `+1,157억`(초록)이다.
- 잔고 기준 부호(`−1,157억`)는 **T계정 펼쳐보기 안에서만** 쓰고, 그 표의 머리에 "잔고 증감 기준 · 부채 항목 감소 = 방출"을 명시한다. T계정 안에서는 초록/빨강을 쓰지 말고 중립색 + 부호만 쓴다.
- 수준값(잔액, 인수액 등)에는 초록/빨강을 쓰지 않는다. 기존 입찰 표의 "연준 인수" 초록색은 제거.
- 스트레스 지표의 상태 점은 같은 초록/빨강을 쓰되, 의미는 "경계선 아래/위"다.

### 3.3 숫자·날짜 표기

- 금액: `$5.5조`, `1,157억` (억 단위는 정수, 천 단위 쉼표, 소수점 없음). 조 단위는 소수 1자리.
- 본문 문장 안에서는 "1,157억 달러", 표·막대 라벨에서는 "+1,157억".
- 음수 기호는 `−`(U+2212).
- 날짜: 본문은 "9월 9일", 월간 지표는 "7월"(일자 붙이지 않음). ISO 표기는 펼쳐보기 표에서만.
- 반올림 차이 처리 같은 제작 메모는 화면에 내보내지 않는다.

## 4. 칸별 명세

각 칸은 **데이터 → 계산 → 그림 → 문장** 순으로 적었습니다. 시리즈 ID는 6장 참고.

### 요약 (다섯 문장)

각 칸의 "요약 문장"을 그대로 모은 것. 클릭하면 해당 칸으로 스크롤. 아래에 고정 문구: "매주 오는 분은 여기까지. 아래는 각 문장의 근거입니다."

### 01 얼마나

**계산**
- `NL = 연준 총자산 − TGA − 역레포` (주간, H.4.1 수요일 기준)
- `ΔNL = NL(t) − NL(t−N주)`, `ΔNL% = ΔNL / NL(t−N주)`
- `pctl` = 최근 5년 동안의 모든 N주 변화값 분포에서 이번 ΔNL의 백분위
- `NL_yoy`, `M2_yoy` = 전년 동기 대비 증감률. M2는 월간이므로 최신 월 값과 그 달을 표시

**그림 A — 분해 막대** (한 줄 가로 막대, 전체 = 연준 총자산)
- 순유동성(잉크색, 라벨과 금액을 막대 안에) | TGA(중립) | 역레포(더 옅은 중립). 폭은 실제 비율.
- 막대 아래 범례에 TGA·역레포 잔액. 그 아래 설명 문단(목업 문구 그대로, TGA 뜻풀이 포함).

**그림 B — "이 정도면 큰 변화인가"**
- 순유동성 **달러 수준** 선 차트, 최근 1년. t−N주 지점과 오늘에 점, 그 사이 구간을 ΔNL 부호 색으로 옅게 칠함.
- 그 아래 백분위 띠: 왼쪽 끝 "지난 5년 중 가장 큰 감소", 가운데 "변화 없음", 오른쪽 끝 "가장 큰 증가". 점 위치 = ΔNL을 [5년 최소, 0, 5년 최대]에 구간별 선형으로 놓은 자리. 점 색 = 부호 색.
- 문장: `지난 5년의 {N}주 변화 가운데 {상위|하위} {p}%에 해당합니다.`

**그림 C — 순유동성과 M2**
- 카드 두 장: 순유동성(수준, 전년비, 기준일·주간) / M2(수준, 전년비, 기준월·월간). 카드의 선 견본(실선/점선)이 차트 범례를 겸함. 정의 문구는 목업 그대로.
- 전년비 선 차트: 순유동성 = 잉크 실선, M2 = `#3E5C76` 점선. 0% 선 강조. x축은 연도 라벨을 **연 1회만**.
- 버튼: `5년`(기본) / `최근 2년 확대`(y축 자동 재조정) / `S&P 500 겹치기`(토글, 켜짐 상태를 버튼 모양으로 표시. 보조 y축, 전년비).
- 주석: 전년비가 한 주 사이 5%p 이상 급변한 지점 가운데, 1년 전 같은 주에 수준이 급변했던 경우 "기저효과" 주석을 단다. 최소한 2024년 3월(1년 전 SVB)은 고정 주석으로.
- 해석 문장 규칙:
  - `|NL_yoy| < 2%p` 이고 `M2_yoy ≥ 3%`: "밑돈은 1년 전과 비슷한데 M2는 {x}% 늘었습니다. 돈이 연준 바깥에서 만들어지고 있다는 뜻입니다."
  - `NL_yoy`와 `M2_yoy` 부호가 같고 둘 다 |·| ≥ 2: "밑돈과 M2가 함께 {늘고|줄고} 있습니다."
  - 그 외: "밑돈은 {a}%, M2는 {b}% 변했습니다." (해석 없이)
  - 원인 귀속("은행 대출과 재정 지출")은 넣지 않는다.

**결론 문장**: `시장에 도는 돈은 {NL}조 달러, {N}주 전보다 {|ΔNL|}억 달러({ΔNL%}) {늘었습니다|줄었습니다}.`
**요약 문장**: `유동성은 {N}주간 {|ΔNL|}억 달러 {늘었습니다|줄었습니다}.`
`|ΔNL%| < 0.3%`이면 "거의 그대로입니다"로 대체.

### 02 어디서

**계산** (모두 "순유동성에 준 영향" 부호)
- `c_fed = Δ연준 총자산`, `c_tga = −ΔTGA`, `c_rrp = −Δ역레포`, 합 = ΔNL (항등식 검증)
- 연준 세부: Δ국채(SOMA), ΔMBS, Δ기타. 설명 줄은 고정 문구가 아니라 **|Δ|가 큰 순서로 생성**: `{가장 큰 항목} {값}이 대부분, {다음 항목} {값}`. 국채가 늘었는데 "QT 만기상환"이라고 쓰는 일이 없도록.

**그림 — 기여 막대** (가로, 0 축 기준 좌우 발산)
- 행: 재무부(TGA) / 역레포 / 연준 / 합계. 0 축 위치는 음수 최대값에 맞춰 동적으로. 합계는 잉크색.
- 각 행 설명 줄은 `{잔고 방향} = {방출|흡수}. {한 줄 사유}` 꼴:
  - TGA 감소: "TGA 잔고 감소 = 방출. 거둔 돈보다 쓴 돈이 많았음" / 증가: "TGA 잔고 증가 = 흡수. 쓴 돈보다 거둔 돈(세금·국채)이 많았음"
  - 역레포 감소: "역레포 잔고 감소 = 방출. MMF가 연준에 넣어둔 돈을 시중으로 인출" / 증가: "역레포 잔고 증가 = 흡수. MMF가 남는 돈을 연준에 예치"
  - 연준 증가: "자산 증가 = 방출. {세부}" / 감소: "자산 감소 = 흡수. {세부}"

**판정 상자 "이어질까"** — 분류 규칙
- `share_i = |c_i| / (|c_fed| + |c_tga| + |c_rrp|)`, 주도 요인 = ΔNL과 부호가 같은 것 중 share 최대
- 주도 = TGA, share ≥ 0.5 → **"일회성일 가능성이 큼"** + "재무부가 TGA를 풀어 생긴 유동성은 TGA를 다시 채울 때 도로 흡수됩니다." (흡수 쪽이면: "TGA를 채우느라 생긴 흡수는 재무부가 지출하면 되돌려집니다.")
- 주도 = 연준, share ≥ 0.5 → **"이어질 가능성이 큼"** + "연준 자산 변화로 생긴 유동성은 정책이 바뀌기 전까지 같은 방향으로 이어집니다."
- 주도 = 역레포, share ≥ 0.5 → **"남은 여력에 달림"** + "역레포 잔고는 {잔액}. 바닥에 가까울수록 더 나올 돈이 없습니다."
- 그 외 → **"여러 요인이 섞임"** + 상위 두 요인 나열.
- 상자 하단 막대: TGA 현재 잔고 vs 재무부 목표 잔고(설정값, 8장). 목표가 비면 막대 생략.

**결론 문장**: 기여 절대값 1·2위를 쓴다. 부호가 반대면 "반대로"로 잇는다.
`{주체1}가 {TGA에서|역레포에서|자산을 늘려} {x}억 달러를 {시중에 풀었습니다|흡수했습니다}. {주체2}는 {반대로|역시} {y}억 달러를 {…}.`
**요약 문장**: 판정 분류에 따라. 예) TGA 주도 방출: "재무부가 TGA 잔고를 시중에 푼 결과라 오래가긴 어렵습니다."

**펼쳐보기**: 기존 연준 T계정(자산/부채 스택 + 4주 Δ 표 + SOMA 만기별)을 그대로. 단,
- 부채 쪽 이름 없는 띠에 라벨(역레포, 기타 부채) 부여
- 3.2의 T계정 부호·색 규칙 적용
- "자료 부족" 항목은 9장 규칙대로

### 03 어디로

**계산**
- `Δ지급준비금 = ΔNL − Δ(현금통화·기타)` (기존 항등식 그대로)
- `res_share = Δ지급준비금 / ΔNL`

**그림 A — 분해 막대**: ΔNL 전체를 한 줄로, 지급준비금 몫(부호 색) | 현금통화·기타(중립). 두 항목 부호가 다르면 막대 대신 두 줄 기여 막대(02와 같은 양식)로 대체.

**그림 B — "지금 지급준비금은 넉넉한 수준인가"**
- 가로 눈금: 빠듯(빨강) | 경계(중립) | 넉넉(초록). 구간 경계는 설정값(8장). 단위도 설정에 따름(달러 수준 또는 GDP 대비 %).
- 현재 위치 점 + 수치. 설정이 비면 그림 B 전체를 숨긴다.

**참고 블록** (점선으로 분리, 작은 카드 2장)
- 은행 예금 Δ (H.8 주간, 실제 비교 기간 표기) / 단기 국채 잔액 Δ (MSPD 월간, "돈이 앉은 곳이 아니라 돈을 빨아들이는 쪽")
- 머리에 "기간과 층위가 달라 위 숫자와 더하지 않습니다". 본 그림과 같은 양식의 막대·게이지를 쓰지 않는다.
- MMF 잔고는 출처가 정해지면 세 번째 카드로. 그전에는 화면에 내보내지 않는다.

**결론 문장**
- `res_share ≥ 0.7`: `{늘어난|줄어든} {|ΔNL|}억 달러 중 {|Δ지급준비금|}억이 은행 지급준비금{으로 들어갔습니다|에서 빠졌습니다}.`
- 그 외: `지급준비금은 {x}억 {늘고|줄고}, 현금통화·기타는 {y}억 {늘었습니다|줄었습니다}.`

### 04 누가 샀나

**데이터**: 재무부 입찰 결과(결제일 기준, 기본 3개월 창). 종류별(Bills / Notes / Bonds / FRN / TIPS) × 입찰자별(간접 / 프라이머리 딜러 / 직접 / 연준 SOMA / 비경쟁·기타) 낙찰액.

**그림 — 생키**
- 왼쪽 3묶음: 단기채 Bills / 중장기 Notes·Bonds·FRN / 물가연동 TIPS (만기별 표와 같은 분류). 오른쪽 5곳.
- **띠 굵기는 실제 교차 집계값**이어야 한다(목업의 띠 비율은 임의). 노드·띠는 중립색만 사용, 초록/빨강 금지.
- 버튼: `전체` / `단기채 빼고 보기`(Bills 제외 후 다시 그림 — 축척 재계산) / `최근 1개월`.
- 최소 굵기 2px 보장, 너무 가는 띠는 hover/탭 시 값 표시.
- 그림 아래 용어 4줄(목업 문구 그대로).

**주의 상자**: "{총발행}조는 새 빚이 아닙니다". 순증액 = 같은 창의 MSPD 시장성 국채 잔액 변화(월간이라 창이 어긋나면 실제 기간을 명시). 한 카드 안에 기간 창이 둘 이상 섞이지 않게, 표·그림·문장의 창을 하나로 통일하거나 각자 기간을 적는다.

**펼쳐보기**: 기존 만기별 표(발행 · 연준 인수 · 연준 보유 · 보유 변화 · 만기상환 추정). 수준값 색 제거.

**결론 문장**: 최대 수령처 기준.
`{시작월} 이후 찍은 국채 {총액}조 달러 중 {절반 이상인|가장 많은} {x}조를 {최대 수령처}가 가져갔습니다.` ("절반 이상"은 점유율 ≥ 50%일 때만)
추가 규칙: 프라이머리 딜러 점유율이 직전 같은 길이 창보다 5%p 이상 높으면 둘째 문장 "딜러가 떠안은 몫이 {a}%에서 {b}%로 늘었습니다."
**요약 문장**: `새로 찍은 국채는 {절반 이상을|가장 많은 몫을} {최대 수령처}가 받아갔습니다.`

### 05 탈은 없나

**지표 행** (각 행: 풀어 쓴 이름 + 원래 용어 설명 / 경계선이 그려진 눈금 + 점 / 값 + 기준일)

| 표시 이름 | 원 지표 | 눈금 범위 | 경계 | 설명 줄 |
|---|---|---|---|---|
| 초단기 금리 압력 | SOFR − IORB | −10 ~ +10bp | 0 | 0 위로 올라가면 은행들이 돈을 구하기 어렵다는 뜻 |
| 금융여건 종합 | NFCI | −1.0 ~ +1.0 | 0 | 0 위면 평소보다 돈줄이 빡빡함 |
| 부실기업 자금 조달 | 하이일드 스프레드 | 2 ~ 10%p | 설정값(8장) | 벌어질수록 시장이 부도를 걱정함 |
| 연준 긴급대출 | 할인창구 등 대출 잔액 | 설정 | 설정값(8장) | 은행이 연준 창구에서 급전을 빌린 규모 |

- 점 색: 경계 아래 초록, 위 빨강. 값이 눈금 밖이면 끝에 붙이고 수치로 알림.
- 데이터가 없는 행은 회색 글씨 "준비 중 — 데이터 연결 후 표시됩니다". "자료 부족"을 굵게 내보내지 않는다.

**결론 문장**
- 경계 초과 0개: `자금시장에 긴장 신호는 없습니다. {n}개 지표 모두 경계선 아래입니다.`
- 1개 이상: `{지표 이름}{이|가} 경계선을 넘었습니다.` + 나머지 상태 한 줄.
- 요약 문장은 첫 문장만.

### 배경 띠

실질금리 10년 / 달러 3개월 변화 / 산업생산 전년비 / 실업률 / 근원 PCE 전년비. 값과 기준일만, 5열 그리드. 색·판정 없음.

## 5. 문장 생성 구현

- 문장 생성은 **순수 함수 모듈 하나**로 분리한다: 입력 = 계산된 지표 객체, 출력 = `{summary, headline, notes[]}`(칸별). UI는 이 출력만 그린다.
- LLM 호출 금지. 위 규칙의 조건 분기 + 템플릿으로만.
- 조사(이/가, 을/를, 으로/로)는 받침 판별 함수로 처리.
- 증가/감소 양쪽, 13주 기준, 값이 0에 가까운 경우를 포함해 **스냅샷 테스트**를 둔다. 최소 케이스: (a) 2026-09-09 실제값 → 목업과 같은 문장, (b) TGA 증가 주도 흡수, (c) 연준 주도 방출, (d) 역레포 주도, (e) 혼합, (f) ΔNL ≈ 0, (g) 스트레스 지표 1개 초과.
