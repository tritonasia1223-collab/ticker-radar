# 국제 연표

경로 `/#/international-timeline`. 월별 행에 미국·독일·프랑스·영국·일본 열을 맞추며, 공동 사건은 참여국 범위를 합쳐 표시한다. 연간 블록은 해당 연도 상단에, 기간 사건은 시작 시점에 표시한다. 본문은 기존 리치텍스트 도구로 직접 편집한다.

## 저장 — 2026-11-20

[표준 저장 아키텍처](STORAGE-ARCHITECTURE.md)를 적용한다. DB가 확정본이며 사건별 필드 비교 저장을 사용한다. 다른 PC의 독립 변경은 병합하고 같은 필드/삭제와 수정의 경합은 선택을 요구한다. 타이핑은 편집기에서 즉시 반영하며 200ms 버퍼 후 기기 저널에 전달, 600ms idle에 서버로 보낸다. blur·페이지 이동·숨김은 마지막 입력을 확정해 즉시 저장을 요청한다.

활성 페이지에서 5초 주기로 변경 버전을 확인한다. 숨겨진 탭·오프라인·다른 메뉴에서는 정기 조회를 중단하고, 복귀 때 즉시 확인한다. 저장 큐는 조회와 독립적으로 유지한다. 전체 동시 전송은 최대 2개다.

이전 브라우저 저장본은 원문을 백업한 뒤 기본 데이터와의 차이만 이관한다. 각 기기·브라우저·로컬 포트는 별도 원본이므로 해당 브라우저에서 최신 페이지에 접속해야 한다. 충돌은 상단에서 비교한다. 이관을 완료해도 기존 localStorage 원본은 삭제하지 않는다. 자세한 키·이관 진행표·중단 복구는 공통 아키텍처를 참고한다.

상단에 저장/충돌/기기 복구 상태와 변경 이력을 표시한다. 하단 JSON 내보내기는 현재 연표와 삭제 목록을 함께 백업한다. 삭제 목록은 DB에 보관되며 다른 기기에서 복원할 수 있다. 최초 서버 시드는 한 번만 생성한다. 후속 배포가 기본 자료를 바꾸어도 DB 편집본을 자동 덮어쓰지 않는다.

# 국제 연표 로컬 초안

2026-11-17 요청: 미국·유럽·일본을 세로 3열로 비교하고 연도를 맞춘 새 탭. 배포 없이 로컬 화면에서 수정한다.

- 경로: `/#/international-timeline`, 사이드바 **국제 연표**.
- 현재 화면은 **가로 연표**다. 지역을 왼쪽 고정 행에, 연월을 위쪽 고정 열에 놓고 같은 연월의 사건을 공통 CSS Grid 열로 맞춘다. 사건이 있는 월만 표시하며, 설명을 펼쳐도 연월 열은 같은 위치를 유지한다. 월 미상은 해당 연도의 별도 열이다. 기간 자료는 시작 월에 배치하고 원래 기간 문구도 보존한다. 종료 연월을 지정하면 종료 열을 만들고 시작부터 종료까지 하나의 색 블록이 가로로 이어진다. 같은 지역에서 기간이 겹치는 사건은 하위 줄로 나누어 쌓는다. 시간 간격에 비례한 축은 아니며 빈 월은 생략한다. 작은 화면은 연표 안에서 가로 스크롤한다.
- 기본 지역 행은 미국·유럽·일본. 국제 사건은 상단 제목과 모든 지역을 관통하는 빨간 선으로 표시하며 신흥국·산유국을 선택해 행을 추가할 수 있다. 검색, 연대 선택, 모두 접기, 원문 열람을 제공한다. 기본은 제목만 표시하며 사건별로 클릭해 펼친다.
- 열 전체 배경은 없애고 중립 배경에 옅은 세로 구분선만 둔다. 사건 블록에 미국 하늘색·유럽 연두색·일본 살구색을 적용하며 왼쪽에 작은 색 테두리를 둔다. 상단 연도 밴드 아래에는 작은 월 숫자만 표시한다. `년`·`월` 접미사는 생략하고 월 미상은 `—`로 표시한다.
- 국가명은 사건 블록 맨 아래에 작게 표시한다. 미국·일본의 중복 국가명과 국가가 아닌 분류명은 숨긴다. **유럽 행에만 있는 국가 필터**는 선택 국가에 해당하는 사건만 남긴다. 여러 국가 선택, 전체 선택/해제, **이 국가만**을 지원한다. 공동 사건은 선택 국가 중 하나라도 포함하면 보이며 원래 국가 표기는 유지한다. 예: 프랑스만 선택하면 프랑스와 서독·프랑스 공동 사건이 보이고 영국 사건은 숨겨진다. 다른 지역 행에는 영향을 주지 않으며 국제 사건은 공통 맥락으로 계속 표시한다. `국제 통화체제`는 미국으로 정리하고 `국제은행`·`유럽 공동체` 등의 분류는 필터 옵션에서 제외한다.
- 초기 자료는 사용자가 제공한 1970~1979년 메모를 요약·분류한 26개 사건(기본 3열에는 원본 25개, 오일쇼크 병합 후 화면상 23개)이다. 원문은 `client/src/data/international-timeline-source.txt`, 초안은 `client/src/data/international-timeline.ts`에 보존한다. 외부 검증을 완료한 자료가 아니다. 기존 경제사 내용을 가져오거나 덮어쓰지 않는다.
- 펼친 자리에서 제목·설명·국가·연월을 직접 수정한다. 별도 사건 편집창은 없다. 제목과 설명은 기존 `CapRichEditor`/`CapRichText`를 재사용하며, 텍스트 선택 시 기존 글씨 색·하이라이트 도구를 표시한다. 공유 편집기는 기본 동작을 유지하고 선택적 `inline`, `ariaLabel` 속성만 추가했다.
- 입력은 `localStorage` 키 `fiscus-international-timeline-v1`에 자동 저장한다. 기존 저장본을 최초 변경하기 전 `fiscus-international-timeline-before-months-v1`에 보존한다. 월 필드가 없는 이전 저장본은 기존 기간 문자열의 시작 월을 읽는다. `month: null`은 명시적 월 미상이다. 월 선택과 기간 메모는 독립적이며 기간 메모 수정으로 배치가 바뀌지 않는다.
- 서버·공동 저장과 연결되지 않는다. 같은 브라우저와 주소에서 새로고침 후 복원되며, 내보내기로 JSON 사본을 받을 수 있다. 저장 실패 시 입력은 현재 화면에 유지하고 재시도/내보내기를 안내한다. 여러 창 동시 편집 병합은 지원하지 않는다.
- 후속 자료 추가 시 기존 사건 ID를 유지해야 한다. 초기 데이터 배열은 기존 순서를 바꾸지 않고 뒤에 추가하거나 안정적인 ID를 명시한다. 저장본에 없는 새 사건은 원본에서 보충한다. 같은 ID의 사용자 저장본은 우선 보존한다.

추가 피드백: “1970년은 위에 크게 … 밑에는 작게 6월 7월”에 따라 반복 연월 표기를 연도 구간 제목과 작은 월로 분리했다. 국가 표시는 처음에 표시/숨기기 옵션으로 잘못 해석했으나, 사용자의 “기본적으로 오른쪽 끝에 표시”, “프랑스만 켜면 프랑스만 보이게” 정정에 따라 기본 오른쪽 표시와 실제 국가별 사건 필터로 교체했다. 적용 범위는 국제 연표의 보기 방식이며 원문이나 국가 값을 삭제하지 않는다.


## 국제 사건과 기간 일정 · 2026-11-17 추가 피드백

- 사용자 원문: “1970 … 6, 7 …”, “필터에서 국가만”, “그냥 유럽 나라들”, “국제적인 사건 … 전체 한 줄로 병합”, “캘린더나 일정 앱 … 특정 기간으로 일어나는 사건”. 적용 범위는 국제 연표 UI와 브라우저 초안이다.
- 기존의 `1970년 / 6월` 표시를 `1970 / 6`으로 바꾸고 필터는 유럽 국가만 남겼다. 오른쪽에는 실제 국가명만 작게 표시한다.
- 국제 사건은 전체 지역 열을 가로지르는 중립색 한 줄이다. 브레턴우즈 종결과 오일쇼크에 먼저 적용했다. 오일쇼크의 원래 세 사건 ID·제목·본문은 삭제하지 않고 그룹으로 묶어, 펼친 자리에서 지역별 설명을 편집한다. 같은 그룹이라도 기존 날짜가 다르면 별도 행으로 보존한다.
- `국제 사건` 버튼으로 추가하거나, 기존 사건의 `표시 범위 → 전체 열 병합`으로 전환한다. 병합 그룹의 시작/종료·범위 변경은 구성원에 함께 반영하고 제목·본문은 각각 보존한다.
- 캘린더의 시작·종료 입력 방식 참고: https://support.google.com/calendar/answer/72143?hl=en . 연표는 월 단위이므로 종료 연도와 선택적 종료 월을 입력한다. 월을 모르면 연도까지만 표시한다. 기존 자료의 1976년 파운드 위기는 3–12월 기간으로 먼저 적용했다. 임의로 다른 사건의 기간을 추정하지 않는다.
- 기간 사건을 펼쳐 `+ 종료 시점 · 기간 사건`을 누르면 종료 입력이 나타난다. 시작보다 빠른 종료는 거부한다. `기간 해제`로 단일 사건으로 되돌린다. 기간 블록의 제목이나 끝부분을 누르면 같은 블록 안에서 편집한다. 빈 월을 모두 생성하지 않으므로 긴 기간에도 높이가 과도하게 늘어나지 않는다.
- 검증: 타입 검사·프로덕션 빌드 및 단위 테스트 8개 통과. 브라우저에서 프랑스 필터(프랑스 사건 2개 + 국제 사건 유지), 병합된 오일쇼크의 3개 원문 보존, 그룹 월 이동/복원, 지역별↔전체 열 전환, 기간 종료 12→11 변경 후 새로고침 복원 및 12로 원상복구 확인. 390px에서 문서 폭 유지, 연표 내부 가로 스크롤 확인. 로컬 서버/창 유지, 배포 없음.


## 사건별 색 블록 · 2026-11-17 후속 피드백

- 원문: “배경 색을 없애고 … 블럭 별로 색이 들어가게 다시 변경 … 그래야 특정 기간을 표시”. 적용 범위: 국제 연표 로컬 UI.
- 변경 전: 지역 열 전체가 색 배경이고 기간 사건은 시작·진행·종료 행에 각각 표시. 변경 후: 열 배경은 중립색, 사건마다 색 블록. 기간 사건은 동일한 CSS Grid 항목이 시작부터 종료까지 이어져 연도가 바뀌어도 끊어지지 않는다. 반복 진행 문구를 없애고 종료 시점은 블록 하단에 작게 표시한다.
- 기간이 겹치는 동일 지역 사건에는 가로 칸을 할당해 제목·설명·편집 영역이 서로 가리지 않도록 한다. 국제 사건은 전체 열 너비를 사용하며 국제 기간끼리 겹칠 때도 나란히 배치한다. 제목 클릭·인라인 편집·유럽 국가 필터·원문·저장은 유지한다.
- 종료 월을 모를 때는 해당 연도의 알려진 월 다음에 별도 종료 경계를 둔다. 임의의 12월로 표시하지 않는다. 빈 월 생략 방식이므로 블록 높이는 실제 기간에 비례하지 않는다.
- 검증: 타입 검사 및 관련 테스트 12개 통과. 브라우저에서 파운드 위기를 일시적으로 1977.12까지 확장해 1977년 제목을 넘어 이어지는 하나의 블록, 재할인율 사건과 가로 분리, 두 블록 종료선 일치를 확인했다. 이후 원래 1976.12로 복원하고 새로고침 후 저장 상태를 확인했다.

- 저장된 초안에는 `imports`의 `insight-five-countries-20261118-v1`로 한 번만 병합. 기존 기본본과 비교하여 미편집 본문만 정리본으로 갱신하고, 수정된 본문은 리치텍스트 그대로 보존한다. 직접 고친 날짜·라벨·국가, 추가한 사건, 삭제·보관함도 보존. 원문 날짜 접두사 노출을 막기 위해 본문 수정본의 날짜도 유지한다. 없는 이전 ID는 재생성하지 않고, 전체 삭제/사용자 전용 모음도 초기화하지 않는다.
- 첫 반영 직전 전체 저장값을 `fiscus-international-timeline-before-five-countries-20261118`에 백업. 저장은 여전히 해당 브라우저·주소의 localStorage이며 서버·다른 기기로 동기화하는 기능은 추가하지 않았다.
- 검증: 테스트 49개, 타입 검사, Vite 빌드 통과. 로컬에서 200개, 같은 월의 5개 셀 시작선 일치, 프랑스만 필터 시 공동 사건 1회 재배치, 대사건 제목 유지 확인. 프랑스 신규 사건 작성·라벨 부착·날짜 이동·재로딩·삭제·복원을 실제 검증하고 테스트 사건은 로컬 보관함으로 정리했다. 390px에서 문서 폭 390px 유지, 내부 가로 스크롤 확인.

## 2026-11-19 Warm-prism 통합 (철회된 디자인 정책)

기존 glass-spring은 `client/src/lib/warm-prism/{theme.css,spring.js,SKILL.md}`로 흡수했다. 앞선 다크·모바일·공동 사건 글래스 예외 기록보다 이 정책이 우선한다.

- 라이트 단일 테마, 웜 뉴트럴 바탕·순백 면·레몬 강조. 국가와 차트 계열은 의미를 구별하는 토큰 색을 사용한다. 저장된 편집기 마커의 키·색은 유지한다.
- 국가 헤더·팝오버·모달에만 글래스. 유럽 공동 사건은 일반 보조면. 프리즘은 호버/포커스 시 마스크된 1px 가장자리에만 표시한다.
- 다크/모바일 분기 제거. 최소 1080px 데스크톱을 유지하고 좁은 화면에서 좌우 이동한다.
- 높이 펼침, 필터 재배치와 이동은 공유 스프링. 페이지/뷰포트 등장·반복 장식 효과 제거. 기간 호버 150ms 및 접근성 설정은 유지한다.
- 루트 작업본 452개 테스트 통과. 최신 운영 코드 기반 배포 후보는 614개 테스트, TypeScript 검사, Vite 빌드 통과. 로컬 API 없는 화면과 달리 배포 후보 검증 서버는 운영 API를 읽기 전용으로 연결한다.
- 사용자 추가 요청에 따라 운영 배포 대상이다. DB·수집·서버 코드와 운영에 먼저 반영된 편집 기능은 보존한다.

## 2026-11-19 디자인 롤백

사용자 요청으로 warm-prism 적용 전 디자인을 복구했다. 운영 사이트의 일반 화면은 db1e0f1 기준, 국제 연표는 당일 테마 변경 직전 백업 기준이다. 폰트 크기·줄간격·색상·다크 및 반응형·기존 glass-spring을 복원했다. 현재 사건 데이터와 저장/편집 로직은 유지하며, DB와 브라우저 저장값을 초기화하지 않는다. c-bold·hl-gray 마커도 유지한다. warm-prism 모듈은 보관하되 사이트에서 불러오지 않는다. 배포 후보의 데이터·서버·연표 데이터 처리 파일 130개 SHA256 불변 확인, 테스트 616개·TypeScript·Vite 빌드 통과.
